## Goal
Build the flat road ribbons (one merged mesh) and the large ground plane with
the perspective grid texture — the floor of the ASCII world.

## Context
- Contract: `docs/architecture.md` §4.5 (`ROAD_WIDTH`, quad per segment at
  `y = 0.05`, colours, no mitres; `makeGround` plane + `makeGridTexture` spec
  from §4.4 which lives in `ground.ts`). Use `MeshBuilder`/`toGeometry` from
  the PM-owned `src/world/mesh.ts` (read it first).
- Exports: `ROAD_WIDTH: Record<RoadClass, number>`,
  `buildRoadsMesh(roads: Road[]): MeshData` (pure),
  `makeRoadsObject(roads: Road[]): THREE.Mesh` (`MeshBasicMaterial({ vertexColors: true })`),
  `makeGridTexture(): THREE.CanvasTexture` and `makeGround(size = 6000): THREE.Mesh`
  (browser-only; no top-level side effects so node can import the module).
- Segment quad: for `p→q` with unit direction `d` and left normal
  `l = (-d.z, 0, d.x)` scaled by `width/2`, corners `p+l, q+l, q-l, p-l` (in that
  order, normal `(0,1,0)`, winding so `cross(b-a, c-a).y > 0`).
- Write `docs/roads-ground.md` (widths table, colours, grid texture scale).
