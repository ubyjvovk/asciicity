### Reviewer notes
- Shader uses `bright(sampleSub(cell, 0, 0))` instead of `cellMean`. Sub is 1×1 so they are equal; `cellMean`'s 8×8 unroll on SwiftShader blows the e2e 60 s budget (same class of issue T-0050 hit). Documented in the shader comment and `docs/styles/hatch.md`.
- Atlas tiles are clipped to 16×32 so the over-long 45° strokes do not bleed into neighbouring levels.
- `hatchLevel` mirrors the shader with `floor((1 − v^0.45)·7 + 0.5)` (not `Math.round`).
- SwiftShader `style-hatch.png` is a dark cross-hatch (sky → densest ink) with the start overlay still up, same as the other style shots. GPU look from Maidan is for the PM; I did not fail the ticket on that.
