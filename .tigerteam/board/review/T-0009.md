## Goal
The green "NAVIGATION" panel: pure formatters for SECTOR / WORLD / BEARING /
ZONE / FPS rows, a spatial index that names the street or place the player is
at, and the DOM class that renders the rows.

## Context
- Contract: `docs/architecture.md` §4 (module list) — exact behaviour below.
- `src/hud/format.ts` exports:
  - `formatBearing(deg: number): string` → `"267 DEG / WEST"`: degrees rounded,
    modulo 360, zero-padded to 3; compass from 8 sectors of 45° centred on the
    cardinal/ordinal directions, names `NORTH, NORTHEAST, EAST, SOUTHEAST,
    SOUTH, SOUTHWEST, WEST, NORTHWEST`.
  - `formatWorld(x: number, z: number): string` → `"1234.50 / -321.00"` (`toFixed(2)`).
  - `sectorOf(x: number, z: number, cell = 100): string` → with
    `c = floor(x/cell)`, `r = floor(z/cell)`: `E${pad2(c)}` for `c >= 0` else
    `W${pad2(-c)}`; `S${pad2(r)}` for `r >= 0` else `N${pad2(-r)}`; joined with
    `" / "` (e.g. `"E02 / N05"`). `pad2` = at least two digits.
  - `hudRow(label: string, value: string): string` → `label.padEnd(11, '.') + ' ' + value`.
- `src/hud/zone.ts` exports `class ZoneIndex`:
  `constructor(roads: Road[], places: Place[], cell = 50)` buckets every road
  segment of NAMED roads into the cells its bbox (expanded by 30 m) touches;
  `nearestRoad(x, z): { name: string; dist: number } | null` (searches the cell
  of the point and its 8 neighbours);
  `nearestPlace(x, z): { name: string; dist: number } | null` (linear scan);
  `zoneLabel(x, z): string` → road name upper-cased when `dist <= 25`, else
  `"NEAR " + place name upper-cased` when a place is within 300 m, else `"CITY"`.
- `src/hud/hud.ts` exports `interface HudValues { sector: string; world: string; bearing: string; zone: string; fps: number }`
  and `class Hud { constructor(root: HTMLElement); update(v: HudValues): void }`
  which renders into `root`: a `.hud-title` div with text `::: NAVIGATION`, a
  `<pre class="hud-rows">` whose text is the five `hudRow` lines
  (`SECTOR`, `WORLD`, `BEARING`, `ZONE`, `FPS` — fps as an integer) each prefixed
  with `> `, and a `.hud-help` div with `WASD MOVE · MOUSE LOOK · SHIFT RUN`.
  `update` only touches `textContent` (no innerHTML). Import `./hud.css` from
  `hud.ts` (green `#48e06a` monospace on black, 13 px, title brighter, help dim).
- No top-level DOM access in any module (node imports `format.ts`/`zone.ts`;
  `hud.ts` may reference `document` only inside the class).
- Write `docs/hud.md` (row formats with examples, zone rules).
