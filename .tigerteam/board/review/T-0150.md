## Goal
While the `retrocgi` render style is active the game should look like the
glider display from *Escape from New York* (1981): the green NAVIGATION
panel and the minimap disappear, and a cyan overlay appears — a big
`NOSEVIEW` caption, `ALT. 533` / `AIR.. 70` readouts, a dashed reticle, and
landmark tags turned into red target blips. The design is locked in
`docs/architecture.md` §4.11, subsection "`retrocgi` (wave 19 …)",
paragraph "HUD skin" — read it first; it is the contract.

## Context
- The plumbing is done and PM-owned — do NOT edit `src/main.ts`:
  it keeps `document.body.dataset.render` equal to the active style id,
  appends `<div id="noseview">` to `<body>`, constructs
  `new Noseview(root)` once, and calls
  `noseview.update({ altM, x, z, timeS })` every HUD tick (every 4th
  frame) while the style is `retrocgi`, reusing ONE values object.
- Fill in the stub `src/hud/noseview.ts`. The exported names and shapes
  are locked: `interface NoseviewValues { altM; x; z; timeS }`,
  `class Noseview { constructor(root: HTMLElement); update(v: NoseviewValues): void }`.
  Add the pure exports `formatNvAlt(altM: number): string`,
  `formatNvAir(speedMs: number): string`,
  `nvSpeed(prev: { x: number; z: number; timeS: number } | undefined, cur: { x: number; z: number; timeS: number }): number`
  exactly per §4.11. One-line JSDoc on each.
- Pattern to copy: `src/hud/hud.ts` — build the DOM once in the
  constructor with `root.ownerDocument.createElement`, keep element
  references, and in `update` touch only `textContent`. No per-update
  allocation: keep the previous sample in three number fields, not a new
  object (call `nvSpeed` with two reused objects, or inline fields — your
  choice, but `update` must not allocate).
- Constructor builds these children of `root` (class names locked, the
  e2e and the PM review use them): `.nv-title` ("NOSEVIEW"), `.nv-alt`,
  `.nv-air`, `.nv-v`, `.nv-h`, `.nv-box`, `.nv-tick-l`, `.nv-tick-r`.
  Initial text: `ALT. 0` and `AIR.. 0`. `update` writes
  `` `ALT. ${formatNvAlt(v.altM)}` `` and `` `AIR.. ${formatNvAir(shown)}` ``
  with the 0.35 smoothing of §4.11.
- All visuals live in `src/hud/noseview.css` (already imported by the
  stub; keep the two existing rules). Every rule that changes something
  outside `#noseview` must be prefixed `body[data-render='retrocgi']`:
  hide `#hud` and `#mini` with `display: none !important` (main.ts sets
  inline `display` on them), restyle `div.tag` + `div.tag::before` (the
  red blip). Positions, sizes and colours are in §4.11 — use them as
  written (`%` of the viewport, `clamp()` font sizes, `#7fe9ff`,
  `#ff3b30`). Dashed lines: `border-left: 2px dashed` / `border-top: 2px
  dashed` on zero-width / zero-height absolutely-positioned divs.
  `pointer-events: none` on everything; `z-index: 4`.
- New unit file `tests/noseview.test.ts` (vitest, node — import ONLY the
  pure functions; the module imports a `.css`, check how
  `tests/hud.test.ts` or `vitest.config.ts` deals with that and copy it).
  Cases, by name:
  1. `formatNvAlt(533.4)` → `'533'`; `formatNvAlt(533.5)` → `'534'`;
  2. `formatNvAlt(-3)` → `'0'`; `formatNvAlt(0)` → `'0'`;
  3. `formatNvAir(36)` → `'70'`; `formatNvAir(0)` → `'0'`;
  4. `nvSpeed(undefined, cur)` → 0;
  5. `nvSpeed` 10 m along x in 0.5 s → 20; 3 m x + 4 m z in 1 s → 5;
  6. `nvSpeed` with `dt = 0` → 0, with `dt = 2` → 0, with `dt < 0` → 0.
- New e2e `e2e/noseview.spec.ts` (Playwright, DOM only — NO pixel reads,
  NO screenshots). Copy boot + `waitReady` helpers from
  `e2e/amber.spec.ts`. Cases:
  A. `/?synthetic=1&render=retrocgi`: `document.body.dataset.render ===
     'retrocgi'`; `#noseview` computed `display` is `block`;
     `.nv-title` text is `NOSEVIEW`; `.nv-alt` matches `/^ALT\. \d+$/`;
     `.nv-air` matches `/^AIR\.\. \d+$/`; `#hud` computed `display` is
     `none`;
  B. then press `r` once (focus the page first the way
     `e2e/smoke.spec.ts` does for its `R` loop): `body.dataset.render`
     is no longer `retrocgi`, `#noseview` computed `display` is `none`,
     `#hud` computed `display` is not `none`.
- Docs: add a "NOSEVIEW skin (`retrocgi`)" section to `docs/hud.md`

  selector is prefixed with `body[data-render='retrocgi']`.
