## Goal
Implement the effect that makes the game: render the 3D scene at cell
resolution, then draw one coloured glyph per cell on the canvas, all on the
GPU. Plus the renderer/scene/camera factory with the locked constants.

## Context
- Contract: `docs/architecture.md` §4.8 — exports, options/defaults, the
  atlas layout, the pipeline, and the **verbatim fragment shader**. §6 gives
  the `scene.ts` constants (`makeRenderer(canvas: HTMLCanvasElement): THREE.WebGLRenderer`,
  `makeScene(): THREE.Scene`, `makeCamera(aspect: number): THREE.PerspectiveCamera`).
- `glyphIndex(lum, count, gamma)` must mirror the shader formula exactly:
  `floor(clamp(lum,0,1)^gamma · (count−1) + 0.5)` clamped to `[0, count−1]`.
- `buildGlyphAtlas(ramp, tileW, tileH, font, canvas)` takes the canvas so it is
  testable in node with a fake: it sets `canvas.width = ramp.length * tileW`,
  `canvas.height = tileH`, fills black, sets `ctx.font = font`,
  `textAlign = 'center'`, `textBaseline = 'middle'`, `fillStyle = '#fff'`, and
  calls `ctx.fillText(ch, i*tileW + tileW/2, tileH/2)` once per glyph in order.
  Returns `{ canvas, count: ramp.length }`.
- `AsciiRenderer`: the render target is recreated only when `cols/rows`
  change; `render()` allocates nothing. Use `renderer.setRenderTarget(rt)` →
  `renderer.render(scene, camera)` → `setRenderTarget(null)` →
  `renderer.render(quadScene, orthoCamera)`. The scene texture uniform is the
  render target's `.texture`; atlas is a `CanvasTexture` with `LinearFilter`.
- No top-level side effects in either module (node must be able to import
  `ascii.ts` for the unit tests).
- Write `docs/render.md`: pipeline diagram (text), how to change the ramp/cell
  size, and the constants.

- Atlas tile size is fixed at `16×32` inside `AsciiRenderer`, matching §4.8. The ticket exposes `cellW/cellH` but not tile size; happy to promote it to an option if the reviewer wants.
- `render()` uses `renderer.setRenderTarget(rt) → render(scene, camera) → setRenderTarget(null) → render(quadScene, orthoCamera)` exactly as specified and does not allocate — the render target is only rebuilt inside `setSize` when cols/rows actually change.
- `buildGlyphAtlas` is unit-tested with a fake canvas cast via `unknown as HTMLCanvasElement`. In production the browser path in `AsciiRenderer` calls `document.createElement('canvas')` (browser-only, exercised by the T-0011 e2e smoke, not by these unit tests).
