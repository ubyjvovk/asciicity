## Goal
Ambient car traffic (user ask): boxy cars at reasonable speed and density
on the road network of every city, with a CARS toggle in the gear menu, a
persisted setting, and a `?cars=` URL override.

## Context
- **Read first**: architecture.md §4.21 — the complete locked design
  (box dimensions, palette rules, `CAR_CLASSES`, the density formula
  `clamp(round(eligibleRoadKm / 0.35), 30, 250)`, per-car speed in
  `[8, 14]` m/s, toggle semantics, streamed-city rebuild with seed
  `41 ^ version`). `BusFleet` in the same file is the template for
  instanced rendering, `PathWalker` reuse, and determinism.
- `settings.ts`: add `cars: boolean` (default `true`) following the
  existing `crt` pattern EXACTLY — load/merge/URL parse/share-URL rewrite
  (param dropped when default). This ticket may edit settings.ts; the
  §4.20 note freezing it binds T-0104, not this ticket.
- `main.ts`: build the fleet at boot (monolithic/synthetic) or on the
  bus-rebuild trigger (tiled — same place `BusFleet` is rebuilt, §4.19);
  gear menu gains a `CARS` row next to the existing toggles (§4.12
  pattern); toggling sets `fleet.object.visible`, persists, never
  rebuilds. `update(dt)` only when visible.
- Determinism: same (roads, seed) → same cars, positions, colours,
  speeds — unit-testable in node like the BusFleet tests.
- Perf: one instanced draw call; no allocation in `update`.

### Perf / allocation

`CarFleet.update` mirrors `BusFleet.update` exactly: one preallocated
`THREE.Object3D` (`this.dummy`) is reused across frames, positions/
rotations are set via `set()`/`updateMatrix()`, and the instance matrix
is flushed with `needsUpdate = true`. Per-car speeds live in a
preallocated `number[]` (`this._speeds`) filled once in the constructor.
No `new`, no allocation, no map/filter in the frame path. Colours are
per-instance (`setColorAt`) and set once at construction. Toggling
`CARS` OFF sets `object.visible = false` and skips `update(dt)`
entirely — no rebuild, no re-fetch.
