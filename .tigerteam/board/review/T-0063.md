## Goal
Per `docs/architecture.md` §4.13 "Labels": landmarks that carry a fix (or
are extras) get a floating name tag above their roof when within 600 m and
in front of the camera — the cheapest way to make them findable.

## Context
- `src/hud/tags.ts` (pure + thin DOM): `landmarkAnchors(city, fixesForCity)` →
  `{ name, label, x, y: roofY + 4, z }[]` for buildings whose exact name is
  in the fix table (and every extra); `pickTags(anchors, px, pz, maxDist = 600, max = 8)`
  → the nearest `max` within `maxDist` (pure, tested);
  `class Tags { constructor(root: HTMLElement); update(anchors, camera, w, h): void }`
  projects each anchor with `THREE.Vector3.project(camera)`, hides when
  `z > 1` or outside the viewport, positions with `left/top` from NDC; reuses
  a fixed pool of 8 `div.tag` elements (no per-frame allocation).
- `main.ts`: build anchors once after `applyLandmarks`; every 4th frame call
  `tags.update(pickTags(...), camera, w, h)`; `?tags=0` disables; the
  container `#tags` is `pointer-events: none`.
- CSS per §4.13 (`div.tag`).
- e2e: on `/?city=kyiv&at=sophia` after ready, `#tags .tag` visible count ≥ 1
  and one contains `Sophia`.
- Docs: `docs/hud.md` tags section.
