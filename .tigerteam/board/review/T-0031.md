## Goal
On a 390 px phone the HUD panel is 320×336 px, covers most of the upper-right
screen, and intercepts pointer events — so look-drags there never reach the
canvas. Make the HUD click-through and compact on small screens, with a
touch-specific help line.

## Context
- `src/style.css` `#hud` (T-0010) and `src/hud/hud.css` (T-0009);
  `Hud` in `src/hud/hud.ts`; minimap canvas appended into `#hud` (T-0017).
- Changes:
  1. `#hud { pointer-events: none; }` (display-only — applies at all sizes).
  2. `@media (max-width: 700px)` in `src/style.css`: `#hud` width 176 px,
     padding 6 px 8 px; in `src/hud/hud.css` under the same query:
     `.hud-rows` font-size 10 px, `.hud-title` 11 px, `.hud-help` 9 px; and
     `#hud .minimap { width: 90px; height: 90px; }` (CSS size only — the
     canvas keeps its 180 px backing store).
  3. `Hud` constructor gains an optional 2nd parameter
     `help = 'WASD MOVE · MOUSE LOOK · SHIFT RUN'`; `main.ts` passes
     `'LEFT: MOVE · RIGHT: LOOK'` when the touch path is active (the existing
     `'ontouchstart' in window || navigator.maxTouchPoints > 0` check).
  4. `parseUrlOptions` gains `hud: boolean` (default true; `hud=0` hides the
     panel via `hudRoot.style.display = 'none'` and skips `hud.update`, but
     everything else runs).
- Docs: `docs/hud.md` (compact breakpoint, help variants), `docs/integration.md`
  (URL table row `hud`).
