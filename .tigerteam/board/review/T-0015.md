## Goal
Show which landmark the player is looking at: a sixth HUD row `LANDMARK`
naming the nearest *named* building whose centroid is within 80 m and within
±45° of the heading, or `-` when there is none.

## Context
- `src/hud/zone.ts` (`ZoneIndex`) and `src/hud/hud.ts` (`Hud`, `HudValues`)
  from T-0009 — keep every existing export and behaviour; all current tests
  in `tests/hud.test.ts` must pass unchanged.
- `ZoneIndex` constructor gains an optional 4th parameter
  `buildings: Building[] = []`. Named buildings are indexed by footprint
  centroid (mean of `poly` points) into a 50 m cell grid (separate bucket map
  from roads).
- New method `nearestLandmark(x: number, z: number, yaw: number, maxDist = 80, halfAngle = Math.PI / 4): { name: string; dist: number } | null`:
  search the 3×3 cells around `(x, z)` plus enough neighbours to cover
  `maxDist` (`ceil(maxDist / cell)` rings); for each named building compute
  `dist` to its centroid and the angle between the forward vector
  `(sin yaw, −cos yaw)` and `(cx − x, cz − z)`; keep candidates with
  `dist <= maxDist` and `angle <= halfAngle`; return the nearest.
- `HudValues` gains `landmark?: string`; `Hud.update` renders a sixth line
  `> LANDMARK... <value>` (via `hudRow('LANDMARK', v.landmark ?? '-')`) after
  `ZONE` and before `FPS`.
- Append a "Landmark" section to `docs/hud.md` (rule, distances, angle).
