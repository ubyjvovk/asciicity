## Goal
Manhattan's towers are mapped as an outline plus `building:part` ways with
`height` / `min_height` — the real setback massing. Fetch and convert
parts (`minH` base height), drop outlines that contain parts (name moved to
the tallest part), raise the height clamp to 600, and make the mesh and
collision honour `minH`. Contract: `docs/data-format.md` "Building parts"
(rules 1–6) and `src/data/types.ts` `Building.minH` (already committed) —
read both first.

## Context
- `scripts/fetch-osm.mjs`: add `way["building:part"]` and
  `relation["building:part"]["type"="multipolygon"]` to the Overpass query.
- `scripts/osm-convert.mjs`: height parsing for parts (reuse the `height`
  / `building:levels` logic; `min_height` ft-aware like `height`;
  `building:min_level × 3.3`); emit `minH` only when > 0 and `< h − 1`;
  outline replacement per rule 3 (centroid-in-outline test — use the
  existing point-in-polygon helper; bucket outlines by bbox so 52 k × 15 k
  stays fast); clamp `h` to `[3, 600]` (was 320) for outlines AND parts.
  Keep every existing output byte-identical when no parts exist (London /
  Kyiv / SF fixture tests must not change).
- `src/data/validate.ts`: `h` in `[3, 600]`; `minH` optional finite in
  `[0, h − 1)`; error messages in the existing style.
- `src/world/buildings.ts`: walls from `minH` to `h` (default 0); when
  `minH > 0` emit a downward-facing bottom cap at `minH` (the underside is
  visible from the street); shapes (dome/spire/tower caps) sit on `h` as
  today. Windows texture unchanged.
- `src/world/collision.ts`: skip footprints with `minH >= 2.5` when
  bucketing (architecture §4.6 wave 10).
- Tests (names verbatim):
  - `tests/osm-convert.test.ts`: `'building:part with height and min_height converts to h and minH'`,
    `'building:part from levels uses ×3.3 (+2 for h, +0 for minH)'`,
    `'an outline containing parts is dropped and its name moves to the tallest part'`,
    `'an outline without parts and a part outside every outline are kept unchanged'`,
    `'heights clamp to [3, 600]'`
  - `tests/validate.test.ts`: `'minH must be a finite number in [0, h − 1)'`, `'h up to 600 is valid'`
  - `tests/buildings.test.ts`: `'walls of a building with minH start at minH and a bottom cap is emitted'`
  - `tests/collision.test.ts`: `'footprints with minH >= 2.5 do not block'`
- `docs/integration.md`: a "Building parts" note (what changes for
  datasets on re-fetch; SF/London/Kyiv not re-fetched here).
