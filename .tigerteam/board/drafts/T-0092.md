## Goal
Add the Cloudflare Web Analytics beacon to the site so page views on the
GitHub Pages deployment are counted. This is a verbatim snippet insertion —
no design decisions.

## Context
- `index.html` is the single page (Vite entry). Insert the snippet below
  **immediately before the closing `</body>` tag**, on its own lines, after
  the existing `<script type="module" src="/src/main.ts"></script>` line,
  indented like its neighbours (4 spaces). Copy it EXACTLY — same token,
  same attributes, single quotes and all; do not add `async`/`defer`, do
  not gate it on hostname, do not move it into `src/`:

```html
    <!-- Cloudflare Web Analytics --><script type='module' src='https://static.cloudflareinsights.com/beacon.min.js' data-cf-beacon='{"token": "810b464b788a4ab6a437744ac7348a0c"}'></script><!-- End Cloudflare Web Analytics -->
```

- Vite leaves `<script>` tags with absolute `https://` URLs untouched at
  build time, so the built page carries the tag verbatim. Verify that
  rather than assuming it.
- `README.md`: add a short `## Analytics` section right after the
  `## Social preview` section: one or two sentences saying the page loads
  the Cloudflare Web Analytics beacon (`static.cloudflareinsights.com/beacon.min.js`,
  cookieless, client-side only) from `index.html`, and that removing that
  one `<script>` line disables it. Do not paste the token into the README.

## Acceptance criteria
- [ ] `grep -c 'static.cloudflareinsights.com/beacon.min.js' index.html` prints `1`, and the line matches the snippet above byte-for-byte (`grep -F` with the full snippet exits 0)
- [ ] The snippet line is the last element before `</body>`
- [ ] `npm run build` exits 0 and `grep -F 'data-cf-beacon' dist/index.html` exits 0
- [ ] `bash .tigerteam/scripts/run-tests.sh` exits 0 (unit tests unchanged)

- [ ] No files changed outside scope; `dist/` is not committed
