Replace the stub `src/render/styles/dither.ts` with the real **dither + gameboy (Bayer 8×8)** look,
exactly as specified in `docs/architecture.md` §4.11 "dither / gameboy". One file,
one shader, pure helpers unit-tested in node.

  helpers — `sampleSub`, `cellMean`, `bright`, `shaped`, `tintOf`,
  `linearDepth`) and `src/render/styles/ascii.ts` (the reference style:
  how the atlas, `makeUniforms` and the fragment fit together) before
  writing code. Keep the module's `export const STYLES` and the id(s) the
  stub declares; keep cell/sub/needsDepth per §4.11.

  spec for the shader); pure helpers never touch `document`.

  unless §4.11 says otherwise; build them in `makeUniforms` via
  `ctx.makeCanvas`; `dispose` frees the texture.
- `docs/styles/dither.md`: the algorithm in prose, the pure exports, and a
  note on what the shader does per pixel.
