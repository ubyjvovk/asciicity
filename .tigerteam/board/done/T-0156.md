## Goal
Add neon signs "here and there" to the cyberpunk city, like the reference:
vertical blade signs sticking out of street-facing walls and flat panel
signs above shopfronts, with legible glowing tube lettering in city-
appropriate words (English / Ukrainian / Japanese), a little flicker, and
coloured light spilling onto the walls and the wet street. It is an
EXPERIMENTAL layer (on by default, `N` toggles — already wired). Contract:
docs/architecture.md §4.11 "`cyberpunk` v2 (wave 20b)" → "Neon signs" and
"Plumbing" — sizes, probabilities, words and colours are locked there.

## Context
- Layer contract: `src/render/punk/layer.ts` (PM-owned). Stub
  `src/render/punk/neon.ts` is registered (EXPERIMENTAL in `layers.ts`);
  replace its body, keep `export function createNeonLayer(): PunkLayer` with
  `id: 'neon'`, `rainPassThrough: true`.
- Streaming: `CellStreamer` (`cells.ts`, PM-owned) buildRadius 400,
  disposeRadius 550, maxBuildsPerFrame 1. Placement only considers the roads
  of the same `CellData` (`cell.roads`).
- Pure placement `src/render/punk/neonplace.ts` (NO `three/webgpu`, NO DOM):
  `placeSigns(buildings, roads, heightAt, cityId) → Sign[]` with
  `Sign = { buildingId, kind: 'blade'|'panel', word, color: string, x, y, z (centre), nx, nz (wall outward normal), width, height, flicker: boolean }`,
  seeded `mulberry32(id ^ 0x9e3779b9)` per building (copy the PRNG from
  `src/world/textures.ts`, do not edit that file); `WORDS[cityId]` with the
  §4.11 lists (fallback list for unknown ids); `NEON_COLORS`. Seat with
  `normalizeRing` / `ringHeights` from `src/world/buildings.ts` like walls
  (outward normal of CCW edge a→b = (dz, −dx)/len).
- Atlas `src/render/punk/neonatlas.ts` (browser-only, canvas 2D): one
  2048² `CanvasTexture`, ≤ 64 slots keyed `kind|word|color`, LRU-free
  (first 64 distinct keys; beyond that reuse slot `hash % 64`); per slot:
  near-black backing, rounded tube border, text drawn twice (wide glow via
  `shadowBlur` + colour, then a thin near-white core); blade slots stack
  glyphs vertically (one glyph per row, works for Latin, Cyrillic and CJK).
  Export `getSlotUv(key) → { u0, v0, u1, v1 }`. Set `colorSpace = SRGBColorSpace`.
- Geometry per cell: one merged face mesh (quads with atlas UVs; blades get
  two faces, the back one mirrored so the text reads correctly from both
  sides), one merged dark frame/bracket mesh. Face material
  `MeshStandardNodeMaterial`: colour 0.02, `emissiveNode` = atlas × 4 ×
  flicker, where flicker comes from a per-vertex attribute (flicker seed)
  and a time uniform (off 5 % of the time for flickering signs).
- Spill: ≤ 4 `THREE.PointLight` (sign colour, intensity 6, distance 14)
  re-assigned every 0.25 s to the nearest signs in the camera frustum within
  150 m, intensity faded in/out over 0.3 s. Stats: `signs`, `visible`,
  `lights`, `slots` + streamer stats.
- **Never open or read any `.png`/`.jpg`.** Word lists must contain no
  brand/trademark names (the §4.11 lists are fine).
