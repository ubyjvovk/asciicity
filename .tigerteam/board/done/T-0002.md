## Goal
Implement the data layer: WGS84 → local-metre projection, a strict validator
for `CityData`, the deterministic synthetic test city, and the fetch-based
loader. Everything here is pure and unit-tested in node.

## Context
- Contract: `docs/architecture.md` §3 and §4 (module list for `src/geo.ts`,
  `src/data/*`), `docs/data-format.md` (coordinate formulas, schema rules,
  synthetic-city spec). Types are in `src/data/types.ts` (PM-owned, do not edit).
- Exports (exact names):
  - `src/geo.ts`: `M_PER_DEG_LAT = 110574`, `M_PER_DEG_LON_EQ = 111320`,
    `project(lon: number, lat: number, origin: {lat: number; lon: number}): Vec2`,
    `unproject(x: number, z: number, origin): {lon: number; lat: number}`.
  - `src/data/validate.ts`: `validateCity(raw: unknown): CityData` — returns the
    same object (typed) when valid; throws `Error` whose message contains the
    JSON-ish path of the first problem, e.g. `buildings[3].poly`, `roads[0].cls`.
    Checks: `v === 1`; origin/bbox finite; every rule under "Schema (v: 1)" in
    data-format.md including unique ids per array and `h` in `[3, 320]`.
  - `src/data/synthetic.ts`: `syntheticCity(seed = 1, blocks = 12): CityData`
    exactly per data-format.md "Synthetic city" (mulberry32 PRNG; include the
    PRNG as `mulberry32(seed): () => number` export).
  - `src/data/load.ts`: `loadCity(url: string, fetchImpl: typeof fetch = fetch): Promise<CityData>`
    — `fetchImpl(url)`, throw `Error('city data: HTTP <status>')` when `!ok`,
    else `validateCity(await res.json())`.
- Append a short "Validation errors" subsection to `docs/data-format.md`
  listing the error message format and the checks performed.
