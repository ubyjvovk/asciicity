## Goal
Replace the `lowpoly` stub with the real style: the *Money for Nothing*
music-video look — crude flat-shaded facets, big square pixels, eight
screaming saturated colours plus a grey ramp, and thick black outlines
where polygons meet. The formula is locked in `docs/architecture.md`
§4.11, subsection "`lowpoly` (wave 15, T-0120)" — read it first; it is the
contract. The stub already ships and is registered (`STYLE_ORDER`,
`styles/index.ts`, `R` cycles to it, `?render=lowpoly` selects it).

## Context
- Rewrite `src/render/styles/lowpoly.ts` wholesale. Keep the exported
  shape: `export const STYLES: readonly RenderStyle[]` with ONE entry,
  `id: 'lowpoly'`, `label: 'LOWPOLY'`, `cellW: 6`, `cellH: 6`, `subX: 2`,
  `subY: 2`, `needsDepth: true`.
- Pattern to copy: `src/render/styles/pico8.ts` (palette as a
  `uniform vec3 palette[8]` array set in `makeUniforms`, nearest-colour
  loop with a constant-index `for`) and `src/render/styles/edges.ts` (the
  five `linearDepth` samples and the sky / inverse-depth second-difference
  test). Read `src/render/style.ts` for the prelude helpers
  (`cellMean`, `bright`, `shaped`, `tintOf`, `linearDepth`) — never
  redeclare prelude uniforms or shadow `bright`/`shaped`.
- Outline neighbours are one CELL apart: `stepUv = 1.0 / grid` (the
  `edges` style uses `1.0 / sceneSize`; that is the only difference in the
  edge test). Import `isEdge` from `./edges` for the pure mirror — do not
  edit `edges.ts`.
- Pure exports, each with a one-line JSDoc, mirroring the shader term for
  term: `LOWPOLY_HUES` (8 × `[r, g, b]` in the §4.11 order),
  `LOWPOLY_LUM` (`[0.22, 0.50, 0.78, 1.0]`), `LOWPOLY_INK`,
  `posterLevel(v: number): number`, `snapHue(tint): number` (`-1` for the
  grey branch, else the index; ties → lower index),
  `lowpolyColour(exposed: [r, g, b], gamma: number): [r, g, b]`.
- New unit file `tests/styles/lowpoly.test.ts` (vitest, node, no WebGL —
  copy the shape of `tests/styles/pico8.test.ts`). Cases, by name:
  1. `LOWPOLY_HUES` has 8 entries matching the §4.11 hex list in order;
  2. `posterLevel`: 0 → 0, 0.249 → 0, 0.25 → 1, 0.5 → 2, 0.75 → 3, 1 → 3;
  3. `snapHue` of each hue returns its own index;
  4. `snapHue([1, 1, 1])` and `snapHue([1, 0.9, 0.85])` return -1 (grey);
  5. `snapHue([1, 0.2, 0.2])` → 0 (red), `snapHue([0.2, 0.2, 1])` → 5 (blue);
  6. `lowpolyColour([0, 0, 0], 0.45)` → `[0, 0, 0]`-ish: every channel ≤ 0.22;
  7. `lowpolyColour([1, 1, 1], 0.45)` → `[1, 1, 1]` (grey, top band);
  8. `lowpolyColour([1, 0.1, 0.1], 0.45)` → each channel equals
     `LOWPOLY_HUES[0] · LOWPOLY_LUM[3]` (`toBeCloseTo`);
  9. `lowpolyColour` output is always one of the 4 × 9 combinations
     (hue or grey × band) for a grid of random inputs: check that
     `out / LOWPOLY_LUM[posterLevel(v)]` is a hue or `[1,1,1]`.
- New doc `docs/styles/lowpoly.md`: copy the shape of
  `docs/styles/pico8.md` — cell/sub/depth line, "Algorithm (per cell)"
  numbered steps, shader notes (palette uniform, cell-spaced edge
