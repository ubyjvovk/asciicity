## Goal
Deploy the built site to GitHub Pages on every push to `main` so the game is
playable at `https://ubyjvovk.github.io/asciicity/`.

## Context
- `vite.config.ts` reads `VITE_BASE` (T-0001); Pages serves under `/asciicity/`.
- Workflow `.github/workflows/pages.yml`, name `pages`: trigger `push` to
  `main` + `workflow_dispatch`; `permissions: { contents: read, pages: write, id-token: write }`;
  `concurrency: { group: pages, cancel-in-progress: true }`; job `build`
  (ubuntu-latest): `actions/checkout@v4`, `actions/setup-node@v4` with
  `node-version: 22` and `cache: npm`, `npm ci`, `npm test`,
  `VITE_BASE=/asciicity/ npm run build`, `actions/configure-pages@v5`,
  `actions/upload-pages-artifact@v3` with `path: dist`; job `deploy` needing
  `build`, environment `github-pages` with `url: ${{ steps.deployment.outputs.page_url }}`,
  step `id: deployment` using `actions/deploy-pages@v4`.
- Write `docs/deploy.md`: what the workflow does and the one manual step the
  repo owner must do once (Settings → Pages → Source: **GitHub Actions**).
