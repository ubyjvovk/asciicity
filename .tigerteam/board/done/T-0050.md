## Goal
Turn the ASCII post-pass into a pluggable **render style** system
(`docs/architecture.md` §4.11, contract file `src/render/style.ts` — PM-owned,
read it first): `StyleRenderer` owns the target/quad/common uniforms and
swaps styles; the three themes become the styles `ascii`/`gloom`/`solarized`;
`R`/`Shift+R` cycle, `?render=<id>` selects, a toast names the style; the
`G` key and `theme` option go away (URL aliases stay). Every other id in
`STYLE_ORDER` ships as a **stub** module so eight parallel tickets can each
replace one file without touching anything shared.

## Context
- `src/render/ascii.ts` → `src/render/styles/ascii.ts`: keep `DEFAULT_RAMP`,
  `glyphIndex`, `buildGlyphAtlas`, `themeMix` exported unchanged (move
  `tests/ascii.test.ts` imports); the shader from §4.8 becomes
  `asciiStyle(id, label, theme).fragment` with the §4.8 uniforms it needs
  beyond the prelude (`tAtlas`, `glyphCount`, `theme`) supplied by
  `makeUniforms` — remove uniform declarations the prelude already makes.
  Delete `src/render/ascii.ts` (no shim).
- `src/render/post.ts`: `StyleRenderer` exactly per §4.11 (constructor,
  `styles`, `style`, `setStyle`, `next`, `setSize`, `render`, `cols`, `rows`,
  `dispose`). Material = `ShaderMaterial({ vertexShader: STYLE_VERTEX, fragmentShader: STYLE_PRELUDE + style.fragment, uniforms: { ...common, ...style.makeUniforms(ctx) } })`;
  target `WebGLRenderTarget(cols·subX, rows·subY, { minFilter: Nearest, magFilter: Nearest, depthBuffer: true, depthTexture: needsDepth ? new DepthTexture(...) : undefined })`;
  `render()` updates `time` (seconds since construction), `cameraNear/Far`
  from a `PerspectiveCamera`, calls `style.update?.(...)`, renders the scene
  into the target and the quad to the canvas. `setStyle` disposes the old
  style (`style.dispose?.(uniforms)`, material, target) and rebuilds at the
  current size. `?cell=` overrides apply to every style.
- Stubs: for each of `braille blocks teletext dither pico8 edges hatch matrix`
  create `src/render/styles/<name>.ts` exporting `STYLES` = the id(s) it
  will own (`dither.ts` owns `dither` **and** `gameboy`), each a copy of the
  `ascii` cyber style with the stub's own `id`, `label: '<ID> (TODO)'`, and
  cell/sub/needsDepth per §4.11 — so the cycle, the URL ids and the e2e
  loop work today, and each style ticket replaces one file wholesale.
  `styles/index.ts` builds `STYLES` in `STYLE_ORDER` and throws at import
  if any id is missing or duplicated.
- `src/main.ts`: `parseUrlOptions` gains `render: string` (`?render=`, with
  the `theme`/`gloom` aliases per §4.11; unknown → `ascii`; drop `theme`);
  `StyleRenderer(renderer, STYLES, { initial, cellW, cellH })`; keydown
  `KeyR` (no repeat) → `next(ev.shiftKey ? −1 : 1)`; remove the `KeyG`
  handler; toast `#toast` (create in TS, style in `style.css`: bottom-left,
  HUD green on black, monospace, fades after 1.5 s — text `RENDER: <LABEL>`)
  on every change; `window.__asciicity.render` (id, live) and `.styles`
  (ids). `Hud` help line: append `· R STYLE`.
- `src/hud/share.ts`: `SHARE_KEEP` = `render, time, cell, crt, minimap, hud`
  (drop `theme`); update `tests/share.test.ts` (the `theme=gloom` case
  becomes `render=gloom`).
- `tests/post.test.ts`: pure parts only — `styles/index.ts` has exactly
  `STYLE_ORDER` ids in order; every style's `cols·subX × rows·subY` at
  1920×1080 with its default cell ≤ 640×360; every `fragment` contains
  `void main()`; `STYLE_PRELUDE + fragment` declares no uniform twice
  (regex on `uniform <type> <name>`).
- e2e: replace the theme assertions (if any) with a **style loop**: read
  `__asciicity.styles`, for each press `R`, assert `__asciicity.render`
  advanced to the next id and the canvas has > 2 % non-black pixels
  (paper styles trivially pass), and save `e2e/__shots__/style-<id>.png`
  (use `?cell=3x6` for this test so SwiftShader renders every row); keep
  the other tests.
- Docs: `docs/render.md` rewritten around styles (pipeline, contract
  pointer, how to add a style, list of ids), `docs/integration.md`
  (`?render=`, aliases, `R`, toast, `__asciicity.render/styles`).
