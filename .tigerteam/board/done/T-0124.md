## Goal
Replace the `quest` stub with the real style: the 1993–98 SVGA fantasy look
(Heroes of Might & Magic II, Baldur's Gate, Diablo) — 12 painter's ramps of
20 hue-shifted shades, one-step ordered dither, soft dark outlines at depth
discontinuities, subtle vignette, a banded painted sky driven by
`StyleContext.daylight`. The formula is locked in `docs/architecture.md`
§4.11, subsection "`quest` (wave 16, T-0124)" — read it first; it is the
contract. The stub already ships and is registered (`STYLE_ORDER`,
`styles/index.ts`; `R` cycles to it, `?render=quest` selects it).

## Context
- Rewrite `src/render/styles/quest.ts` wholesale; keep the exported shape:
  `export const STYLES: readonly RenderStyle[]` with ONE entry, `id 'quest'`,
  `label 'QUEST'`, `cellW 3`, `cellH 3`, `subX 1`, `subY 1`, `needsDepth: true`.
- Patterns to copy: `styles/pico8.ts` (gamma step, inline Bayer from `M2`,
  nearest-colour loop over a `vec3` array uniform), `styles/lowpoly.ts`
  (depth edge test, `daylight` uniform seeded in `makeUniforms` and copied
  in `update`), `styles/edges.ts` (`isEdge` — import it for the pure
  mirror; sample neighbours one sub-sample apart, `stepUv = 1.0 /
  sceneSize`, exactly as `edges.ts` does). Read `src/render/style.ts` for
  the prelude helpers; never redeclare prelude uniforms.
- The ramp table is a `THREE.DataTexture` (20 wide × 12 high, `RGBAFormat`,
  `UnsignedByteType`, `NearestFilter`, `needsUpdate = true`) built in
  `makeUniforms` from `QUEST_RAMPS` — no canvas. Dispose it in `dispose`.
  The 11 selection tints (`tintOf(shade 14)` of ramps 1–11) go in
  `uniform vec3 rampTint[11]`.
- Pure exports (one-line JSDoc each), mirroring the shader term for term:
  `QUEST_RAMP_ENDS` (12 × `{ name, dark, light }` hex strings in §4.11
  order), `buildQuestRamps()` and `QUEST_RAMPS` (12 × 20 × `[r, g, b]`),
  `bayer8(x, y)`, `rampFor(tint): number`, `shadeIndex(v, d): number`,
  `questSky(daylight, y01): { ramp: number; index: number }` (before
  dither), `questVignette(p): number`.
- New unit file `tests/styles/quest.test.ts` (copy the shape of
  `tests/styles/pico8.test.ts`). Cases, by name:
  1. `QUEST_RAMPS` is 12 × 20; shade 0 equals `dark`, shade 19 equals
     `light` (toBeCloseTo, 6) for every ramp;
  2. every ramp is monotone non-decreasing in brightness (max channel);
  3. `bayer8` yields 64 distinct values in (0, 1);
  4. `rampFor([1, 1, 1])` and `rampFor([0.9, 0.9, 1])` → 0 (stone);
     `rampFor([0.2, 0.4, 1])` → 8 (sky); `rampFor([1, 0.3, 0.3])` → 10
     (crimson); `rampFor([0.5, 1, 0.4])` → 6 (grass);
  5. `shadeIndex`: (0, −0.5) → 0; (1, 0.49) → 19; (0.5, 0) → 10;
     (0.5, −0.5) → 9; (0.5, 0.49) → 10;
  6. `questSky(1, 0)` → `{ ramp: 8, index: 17 }`, `questSky(1, 1)` →
     `{ 8, 8 }`, `questSky(0.5, 1)` → ramp 11, `questSky(0, 0.5)` → ramp 9,
     index between 2 and 9;
  7. `questVignette([0.5, 0.5])` → 1; `questVignette([0, 0])` → 0.75
     (toBeCloseTo, 3).
- New doc `docs/styles/quest.md` — same shape as `docs/styles/lowpoly.md`:
