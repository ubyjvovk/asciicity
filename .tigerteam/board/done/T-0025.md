## Goal
Make the game playable on phones/tablets: the left half of the screen is a
virtual joystick for moving, the right half a drag surface for looking.

## Context
- `InputState`/`Controls` in `src/player/controls.ts` (keyboard/mouse) stay
  unchanged. `main.ts` currently does `const input = controls.readInput()`;
  with touch it becomes `mergeInput(controls.readInput(), touch.readInput())`
  where `mergeInput` sums axes and clamps to [−1, 1], ORs `sprint`, sums look
  deltas. Export `mergeInput` from `src/player/touch.ts` (pure).
- `src/player/touch.ts` exports: `joystickToAxes(dx: number, dy: number, radius = 60): { forward: number; strafe: number }`
  (pure: `strafe = clamp(dx / radius)`, `forward = clamp(−dy / radius)`; dead
  zone: magnitude < 0.1 → both 0), `mergeInput(a: InputState, b: InputState): InputState`,
  and `class TouchControls { constructor(target: HTMLElement); readInput(): InputState; dispose(): void }`
  using Pointer Events with `pointerType === 'touch'` only: a pointer that
  starts in the left half of `target` is the joystick (origin = start point,
  axes from the current delta each frame); a pointer starting in the right
  half accumulates look deltas (`lookDx += movementX` semantics via the
  delta from the previous event, scaled ×2). Sprint when the joystick
  magnitude exceeds 1.5×radius. Draw a simple joystick ring + knob
  (`touch.css`: two absolutely positioned circles shown only while a joystick
  pointer is active). No top-level DOM access.
- `main.ts`: instantiate `TouchControls(canvas)` when `'ontouchstart' in window`
  or `navigator.maxTouchPoints > 0`; the overlay's first tap must also hide the
  overlay (the existing click handler already fires on tap; pointer lock
  requests fail silently on touch — guard with try/catch).
- Docs: `docs/controls.md` (touch section), `docs/integration.md`.
