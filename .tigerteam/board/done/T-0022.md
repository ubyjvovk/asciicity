## Goal
Let players start at landmarks (`?at=gherkin`) or at any coordinate
(`?at=-0.0984,51.5138,90`) instead of always at Bank.

## Context
- Projection: `project(lon, lat, origin)` from `src/geo.ts`; the city's
  `origin` is `city.origin` at runtime. Yaw from bearing: `yaw = bearingDeg · π/180`.
- New pure module `src/data/spawn.ts`:
  ```ts
  export interface SpawnPoint { x: number; z: number; yaw: number }
  export interface SpawnPreset { lon: number; lat: number; bearingDeg: number; label: string }
  export const SPAWN_PRESETS: Record<string, SpawnPreset>  // keys lower-case
  export function parseAt(param: string | null): { preset?: string; lon?: number; lat?: number; bearingDeg?: number } | null
  export function resolveSpawn(param: string | null, origin: { lat: number; lon: number }, blocked: (p: Vec2) => boolean): SpawnPoint
  ```
  Presets (lon, lat, bearing, label): `bank` (−0.0887, 51.5133, 270, "Bank junction");
  `stpauls` (−0.0950, 51.5139, 270, "Cheapside, facing St Paul's");
  `gherkin` (−0.0800, 51.5132, 0, "St Mary Axe, facing the Gherkin");
  `monument` (−0.0859, 51.5098, 0, "Monument"); `tower` (−0.0760, 51.5095, 180, "Tower Hill");
  `barbican` (−0.0930, 51.5185, 0, "Barbican"); `liverpoolst` (−0.0830, 51.5178, 90, "Liverpool Street");
  `leadenhall` (−0.0845, 51.5128, 90, "Leadenhall Market").
- `parseAt`: `null`/empty → `null`; a name matching a preset key
  (case-insensitive, trimmed) → `{ preset }`; `lon,lat[,bearing]` with finite
  numbers → the numbers; anything else → `null`.
- `resolveSpawn`: pick the point (`null` → `bank`), project to local metres,
  then if `blocked([x, z])` walk `+x` in 1 m steps up to 200 m (the T-0010
  `findSpawnX` rule); return `{ x, z, yaw }`.
- `main.ts`: `parseUrlOptions` gains `at: string | null`; replace the
  hard-coded spawn with `resolveSpawn(opts.at, city.origin, p => collision.blocked(p))`.
  For the synthetic city (`synthetic=1`) presets are meaningless: keep the
  existing `(0, 0, −π/2)` spawn when `synthetic` is set.
- Document in `docs/integration.md` (URL table + preset list) and README.
