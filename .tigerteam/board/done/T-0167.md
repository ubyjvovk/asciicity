photographic PBR maps. The PM added six CC0 ambientCG sets under

### Files changed

### For the reviewer
- **TSL traps I hit (fixed; documented in cyberpunk-facades.md):**
  1. A bare `.toVar()` of `dFdx(uv)` inside a `Fn` is emitted lazily at first use, which put it inside the `If` branch. That is invalid WGSL (derivatives in non-uniform control flow), so the gradients are now explicit `assign`s before the chain.
  2. `select(cond, tn.yx, tn.xy)` on the sampled normal compiled to an if/else that nested and duplicated the whole chain, so I switched it to arithmetic `mix`.
  3. One function feeding two material slots was emitted twice, which gave 20 samples instead of 12. There are now three single-map functions.
- **WebGPU is unverified.** SwiftShader has no WebGPU, so I only verified the WGSL uniformity reasoning via the GLSL structure. Please check that the WebGPU backend compiles with no warnings on the GPU host.
- **Spec narrowing:** the per-building 0/90° swap is applied only to the isotropic sets (concrete, plaster). A swapped brick or standing-seam map would put the courses or seams on their side. All sets get the per-building offset. `pbrWallUv(u, v, seed, allowSwap)` encodes this.
- **Spec reading:** "ground/road = two samples", so the road is anti-tiled too (6 samples, as ground/terrain). §4.11's "doubles the ground ones only" could be read as excluding roads. If fps is tight, dropping the road's second sample is a one-line change in `street.ts` (`antiTiledSample`).
- **Roughness:** roughness = mix(procedural, tex.r, 0.6) as specified, and it is not distance-faded (the mipmaps average it). Because dry asphalt roughness is 0.32, this probably makes dry streets rougher, so please check the gloss in the GPU review.
- **No images viewed:** I never opened any png/jpg; the textures are used by URL only. The visual review is yours.
