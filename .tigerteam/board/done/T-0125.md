## Goal
A Playwright spec that proves the `quest` style (T-0124, `docs/architecture.md`
§4.11 "`quest` (wave 16)") really paints with the 240 ramp colours, bands
its sky, and outlines edges — by measuring pixels like `e2e/lowpoly.spec.ts`.

## Context
- New file `e2e/quest.spec.ts`. Copy the boot helpers (`waitReady`,
  `doubleRaf`, the offscreen-canvas sampler, the `aim` helper) from
  `e2e/lowpoly.spec.ts`; never edit other specs.
- Build the expected colour set from the pure export
  `QUEST_RAMPS` (`import { QUEST_RAMPS } from '../src/render/styles/quest'`),
  plus black. Tolerance 6/255 per channel.
- URL A: `/?synthetic=1&render=quest&cell=3x3&time=12:00`; after ready +
  two double-rAF waits, `aim(page, 0, 0.9)` (north, tilted up) for the sky
  assertions; URL B: same with `time=23:00`.
- Assertions, by name:
  1. non-black fraction > 0.02;
  2. ramp purity: ≥ 0.95 of pixels within 6/255 of some `QUEST_RAMPS`
     colour or black;
  3. distinct colours: ≥ 40 distinct expected colours each on ≥ 0.1 % of
     pixels (ramps are in use — not posterised to a few tones);
  4. sky (URL A, aimed): ≥ 0.05 of pixels lie on ramp 8 (sky) and at least
     4 distinct ramp-8 shades appear (banded gradient); ramp 9 (night)
     < 0.005;
  5. night (URL B, aimed): ≥ 0.05 on ramp 9; ramp 8 < 0.005;
  6. outlines: in the default (un-aimed) noon view, the fraction of pixels
     with shade index ≤ 4 on any ramp is between 0.03 and 0.5.
- If a threshold fails by a small margin, report the measured numbers and
  adjust only within: purity ≥ 0.90, distinct ≥ 24, sky/night ≥ 0.03,
  outlines 0.02–0.6. Anything worse → block with `## Questions`.
