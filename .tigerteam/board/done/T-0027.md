## Goal
The player should start somewhere instantly recognisable — Big Ben — and be
able to walk from Westminster to the City in one world. Refetch the dataset
with a bbox that spans Parliament/Trafalgar Square to Aldgate, and stop
emitting `footway` ribbons (7 009 of 10 307 roads, invisible at cell
resolution, ~40 % of the file).

## Context
- `scripts/fetch-osm.mjs` defaults: bbox becomes
  `-0.130, 51.497, -0.070, 51.521` (minLon, minLat, maxLon, maxLat); the
  **origin stays Bank** (`lat 51.5133, lon -0.0887`) so every existing local
  coordinate, preset and test remains valid. Update the Overpass QL bbox in
  all selectors (they must all use the same numbers) and the doc.
- `scripts/osm-convert.mjs`: `roadClassOf('footway')` now returns `null`
  (footways are dropped like `steps`). Keep `'footway'` in the `RoadClass`
  type/validator for compatibility — just never emit it. Everything else
  (heights, water, ring cleaning) unchanged.
- Expected scale: roughly 2.5–3× the buildings (≥ 6 000), roads without
  footways, the Thames from Westminster Bridge to Tower Bridge, plus places
  like "Westminster", "Trafalgar Square", "Charing Cross", "Embankment".
  Raise the dataset size budget to **10 MB** (tests + docs); Overpass may
  take several minutes — the retry/fallback logic exists; if both endpoints
  fail after retries, block with `## Questions`.
- `tests/osm-convert.test.ts`: update the mapping-table case (`footway` →
  null), the bbox constant if asserted, the size budget, the building
  minimum (≥ 6 000), and add: a building named "Palace of Westminster" (or
  containing "Westminster") exists; some water ring has a point with
  `x < -2000` (the Thames at Westminster is ~2.5 km west of Bank); and
  `validateCity` still passes on the committed file.
- Docs: `docs/data-format.md` (bbox, footway row → "dropped", budget),
  `docs/fetch-osm.md` (new default bbox, summary line quoted).
