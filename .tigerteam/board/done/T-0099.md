## Goal
Prove streaming holds up under movement: tiles unload and dispose, the
loaded set stays bounded, hysteresis prevents thrash, and collision under
the player never gaps at boundaries. Tests only — if these tests expose a
product bug, file `## Questions` with the failing evidence instead of
patching `src/` (out of scope here).

## Context
- **Read first**: architecture.md §4.19; `docs/streaming.md`;
  `e2e/tiles.spec.ts` as landed by T-0095/96/98. Debug surface:
  `__asciicity.tiles = { loaded, pending, version, disposed }`,
  `?tileradius=<m>`. Movement in e2e: fly mode (`F`, look + `W`) covers
  ground fastest; `?tileradius=400`-ish makes transitions cheap.
- The wave-10 flake lessons apply: poll state with tolerant timeouts, pin

  wall-clock assertions tighter than seconds.

**Notes for the reviewer:**
- **“each as a named test”** — the three acceptance behaviours (bounded
  loaded/dispose/version; 3×3 present after; y finite + above ground) all
  require the SAME ~3000 m continuous fly. I folded them into one named test
  that samples all three during the single flight (the move to three
  separate tests would triple an already ~90 s SwiftShader flight and is
  flake-prone). Each acceptance sub-point maps to explicit assertions
  documented in `docs/streaming.md`.
- **Effective fly speed ≈ 35–38 m/s**, not 90: SwiftShader runs ~4–11 fps and
  the frame loop clamps `dt` at 0.1 s, so real-time movement is ~0.4× the
  nominal `FLY_SPRINT_SPEED`. Sprint *is* registering (Shift+W ≈ 3.2× W).
  Hence the 180 s per-test timeout and the 170 s in-test polling deadline;
  the flight itself needs ~85 s here, ~45 s on a faster host.
- **SF's tiled index is sparse** (69 of 110 cells; tiles exist only for
  populated cells). The end-of-fly 3×3 is intersected with the index's keys
  before asserting presence — absent cells have nothing to load. The `j=-4`
  row near the flight path does not exist in the index; this is why the
  naive “all 9 present” check cannot be used.
- No `src/` change, no radii change, no new debug surface; the tests did not
