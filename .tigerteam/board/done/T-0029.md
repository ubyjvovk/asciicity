## Goal
Famous buildings currently get a palette colour by id (Big Ben is blue).
Give the best-known landmarks a fixed, recognisable colour.

## Context
- `src/world/palette.ts` (T-0004): `colorFor(b)` → `LANDMARK_PALETTE[id % 4]`
  for named buildings, else `PALETTE[id % 8]`. Keep both arrays and that
  fallback.
- Add `export const LANDMARK_COLORS: Readonly<Record<string, number>>` keyed
  by the exact OSM `name` (as in `public/data/city.json`):
  `Elizabeth Tower` 0xf7dc6f · `Palace of Westminster` 0xd4a017 ·
  `Westminster Abbey` 0xe8e0c8 · `St Paul's Cathedral` 0xe8e0c8 ·
  `Nelson's Column` 0xe8e0c8 · `National Gallery` 0xe8e0c8 ·
  `Somerset House` 0xe8e0c8 · `London Eye` 0xffffff · `30 St Mary Axe` 0x1abc9c ·
  `20 Fenchurch Street` 0x95a5a6 · `Lloyd's of London` 0x95a5a6 ·
  `Tower 42` 0x3a6fd8 · `Heron Tower` 0x3a6fd8 · `Tower Bridge` 0x5dade2 ·
  `Tower of London` 0xc0392b · `The Monument` 0xf7dc6f · `Monument` 0xf7dc6f ·
  `Bank of England` 0xe8e0c8 · `Royal Exchange` 0xe8e0c8 · `Mansion House` 0xe8e0c8.
- `colorFor`: if `b.name` is a key of `LANDMARK_COLORS` return it; otherwise
  the existing behaviour. Export a helper `landmarkColor(name: string | undefined): number | undefined`.
- Add the table to `docs/world.md` (Palette section).
