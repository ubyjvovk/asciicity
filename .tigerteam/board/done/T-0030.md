## Goal
Water polygons (T-0024) now block every bridge: the default Big Ben spawn is
pushed off Westminster Bridge and nobody can cross the Thames. Mark bridge
roads in the data and let the collision grid treat them as corridors that
override water.

## Context
- Contract already updated (PM): `Road.bridge?: boolean` in `src/data/types.ts`,
  rule in `docs/data-format.md`. Do not edit those files.
- Converter: set `bridge: true` on a road when `tags.bridge` exists and is not
  `'no'` (values `yes`, `viaduct`, `movable`, … all count); omit the key
  otherwise. Update the `.d.ts`, add a fixture highway with `bridge=yes`, and
  regenerate `public/data/city.json` (Overpass; counts within ±5 % of
  `9061 / 7803 / 99 / 31`). Assert in the dataset test that a road named
  `Westminster Bridge` has `bridge: true` and that ≥ 5 roads carry the flag.
- Validator: accept optional boolean `bridge` (`roads[i].bridge` error path
  when present and not boolean); add accept/reject cases in `tests/data.test.ts`.
- Collision (`src/world/collision.ts`): `CollisionGrid` constructor gains an
  optional 3rd argument `corridors: Corridor[] = []` with
  `export interface Corridor { pts: Vec2[]; halfWidth: number }`. Bucket
  corridor segments into the same cell size (bbox expanded by `halfWidth`).
  `blocked(p, r)` returns `false` immediately when `distToSegment(p, a, b) <= halfWidth`
  for any corridor segment in the 3×3 neighbourhood — corridors override
  footprints (water and buildings alike). `resolve` unchanged.
- `main.ts`: build corridors from `city.roads.filter(r => r.bridge)` with
  `halfWidth = ROAD_WIDTH[r.cls] / 2 + 1` (import `ROAD_WIDTH` from
  `src/world/roads.ts`) and pass them as the 3rd constructor argument.
  Nothing else changes; `resolveSpawn` then keeps the `bigben` point on the
  bridge (no +x walk).
- Docs: `docs/collision.md` (corridors), `docs/fetch-osm.md` (bridge flag),
  `docs/integration.md` (collision construction).
