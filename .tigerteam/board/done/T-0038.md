## Goal
Three user requests in one shader change: (1) gloom needs more contrast —
darker structures, even more retained colour; (2) near-white cells (the Sun,
Moon, lit windows) must stay bright in every theme instead of inverting;
(3) a third theme: Solarized-light — muted coloured ink on cream,
almost wireframe-like. `G` cycles black → gloom → solarized.

## Context
- `src/render/ascii.ts` (T-0033/T-0037). Replace the boolean invert with a
  numeric theme: `AsciiOptions.theme: number` (0 cyber, 1 gloom,
  2 solarized; default 0), uniform `theme` (float), `setTheme(t: number)`,
  `get theme(): number` (`invert`/`setInvert` are removed — grep confirms no
  other callers besides `main.ts`).
- Fragment shader: replace the block after `float mask = …` with exactly:
  ```glsl
  vec3 normalCol = tint * mask;
  float lumT = dot(tint, vec3(0.299, 0.587, 0.114));
  float hot = smoothstep(0.92, 1.0, clamp(v, 0.0, 1.0)); // sun/moon/lit windows stay bright
  vec3 gWash = mix(vec3(lumT), tint, 0.75) * 0.20;        // darker + more colour than T-0037
  vec3 gGlyph = mix(gWash, tint * 0.9, hot);
  vec3 gloomCol = mix(vec3(0.72, 0.73, 0.75), gGlyph, mask);
  vec3 sInk = mix(vec3(0.396, 0.482, 0.514), tint, 0.5) * 0.75; // solarized base00 ink
  vec3 sGlyph = mix(sInk, vec3(0.71, 0.54, 0.0), hot);          // hot → solarized yellow
  vec3 solCol = mix(vec3(0.992, 0.965, 0.890), sGlyph, mask);   // base3 paper
  vec3 outCol = theme < 0.5 ? normalCol : (theme < 1.5 ? gloomCol : solCol);
  gl_FragColor = vec4(outCol, 1.0);
  ```
  (`v` is the existing exposed max-channel brightness computed earlier in the
  shader — do not recompute it.)
- Replace `gloomMix` with the pure mirror
  `export function themeMix(tint: [number, number, number], v: number, mask: number, theme: number): [number, number, number]`
  implementing the block term-for-term (smoothstep included:
  `t = clamp((x − 0.92) / 0.08, 0, 1); t·t·(3 − 2t)`).
- `src/main.ts`: `parseUrlOptions` — `theme` param accepting
  `cyber|gloom|solarized|0|1|2` (invalid → 0); keep `gloom=1` as an alias for
  theme 1 (theme param wins when both present). Pass `theme` to the renderer;
  `KeyG` now cycles `(theme + 1) % 3`.
- Docs: `docs/render.md` — Themes section replacing Gloom mode (quote the new
  shader block verbatim, list the three themes and constants);
  `docs/integration.md` — `theme` URL row (note the `gloom` alias) + key `G`
  cycles.
- Flag for the PM: architecture.md §4.8 needs the same block after accept.
