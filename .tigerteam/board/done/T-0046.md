## Goal
With no `?city=` the start overlay lets the player choose LONDON or KYIV;
pressing Esc (pointer-lock loss) shows a pause menu with `CLICK TO RESUME`,
`COPY LINK TO HERE` (a URL that reopens this city at this exact spot and
heading) and `SWITCH CITY`. Spec: `docs/architecture.md` §4.10.

## Context
- `src/hud/share.ts` (pure): `buildShareUrl(href, cityId, state, origin)`
  exactly per §4.10 — keep only `theme`, `time`, `cell`, `crt`, `minimap`,
  `hud` from `href`'s query (in that order, when present), then `city`, then
  `at=<lon>,<lat>,<bearing>` with lon/lat from `unproject(x, z, origin)`
  (`src/geo.ts`) at 5 decimals and bearing `Math.round(yawToBearingDeg(yaw))`
  (`src/player/controls.ts`). Return `origin + pathname + '?' + params`
  (use the `URL` class; drop hash).
- `index.html`: the overlay keeps `<h1>` and `<p>`; add an empty
  `<div id="menu"></div>` after `<p>`. `main.ts` fills it:
  - **Picker** (no `?city=`, not synthetic): one `<button class="city">` per
    `CITIES` entry — text `<label>` on the first line and `<blurb>` smaller
    below; keys `1`…`9` select by index. On choice: `history.replaceState`
    with the current search plus `city=<id>`, then continue the normal boot
    (this means data loading moves after the choice — restructure `main()`
    so the renderer/scene are built once the city is known; the `p` line
    reads `CHOOSE A CITY` while picking, `CLICK TO ENTER` after).
    `?synthetic=1` or a valid `?city=` skip the picker entirely.
  - **Pause** (`overlay.resume` mode): `CLICK TO RESUME` stays as the `<p>`;
    the menu shows two buttons: `COPY LINK TO HERE` → builds the URL,
    `navigator.clipboard?.writeText(url).catch(() => {})`, writes it into a
    read-only `<input id="share">` under the buttons and selects it, sets
    the button text to `COPIED` for 1.5 s; `SWITCH CITY` → `location.href =
    location.pathname + '?' + (current search minus city and at)` (empty
    search → just the pathname). Buttons call `stopPropagation()` on click
    so the overlay's own click-to-resume does not fire; clicking anywhere
    else resumes as today.
- `src/style.css`: `#menu` column layout, buttons in the HUD green on black
  with a 1 px green border, monospace, letter-spacing like `#overlay p`;
  `#share` full-width read-only input, same palette; on the compact/mobile
  breakpoint (see existing media queries) buttons stack full-width.
- Docs: `docs/integration.md` — the picker, the pause menu, the share URL
  format with an example.

## Rework (attempt 2)

Gate is green and the picker + pause menu look right on the GPU (screenshots reviewed by the PM). One functional defect blocks acceptance:

**What failed:** clicking the read-only `#share` input bubbles to the overlay's click handler, which hides the overlay and re-requests pointer lock — verified headless: after `COPY LINK TO HERE`, `page.locator('#share').click()` leaves `#overlay.style.display === 'none'`. The field exists precisely for browsers that deny `navigator.clipboard` (plain-http hosts, some mobile browsers), and there a user must be able to click/select/copy from it without resuming the game.

**What done looks like:**
1. `#share` (and any future element inside `#menu`) must not resume: stop propagation on `click`, `mousedown` and `pointerdown` for the whole `#menu` container (one listener on `menuRoot`, not per child), so clicking the field only focuses/selects it.
2. Hide the field until it holds a URL (`shareInput.hidden = true` until the first copy) so the pause menu shows just the two buttons before use.
3. Add the check to your headless evidence: after clicking `#share`, `#overlay` is still displayed and `document.activeElement.id === 'share'`; after clicking the overlay background outside `#menu`, the overlay hides (resume still works).
4. `bash scripts/check.sh` green; the existing `tests/share.test.ts` untouched.

Non-blocking notes (no action required): `<blurb>` is a non-standard element — a `<span class="blurb">` would be conventional, change it only if you touch that code anyway; a 1-px `#hud` border peeks above the overlay at the top-right of the picker screen.
