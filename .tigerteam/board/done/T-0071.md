## Context
- The site is served from `https://ubyjvovk.github.io/asciicity/` (deploy
  workflow sets `VITE_BASE=/asciicity/`). Meta URLs must be ABSOLUTE — the
  §4.15 block lists every tag and the exact URLs.
- `scripts/make-og.mjs`: plain node ESM, no new dependencies — use
  `@playwright/test`'s `chromium` (already a devDependency) + `spawn` of
  `npx vite --port 4311 --strictPort` and kill it in `finally`, the same
  boot the e2e uses (`e2e/smoke.spec.ts`: wait for
  `window.__asciicity.ready === true`, then hide `#overlay` via
  `style.display = 'none'`). Launch chromium with
  `{ args: ['--no-sandbox', '--disable-dev-shm-usage'] }`, viewport
  `1200×630`, url `/?time=22:30` (London default spawn — Westminster
  Bridge facing Big Ben, night = lit windows + moon). Two
  double-`requestAnimationFrame` waits after ready before the screenshot so
  the frame is painted. `page.screenshot({ path: 'public/og.png' })`.
- Run the script and COMMIT the generated `public/og.png` (vite copies
  `public/` into `dist/` at build, so the absolute og:image URL resolves).
- `tests/og.test.ts` (node, vitest): read `index.html` as text and assert
  every §4.15 tag; parse `public/og.png` bytes — PNG magic, IHDR width
  1200 / height 630 (bytes 16–23, big-endian) — and `size > 50_000` bytes
  (a black frame compresses far smaller; this catches a blank capture).
- Update the existing `name=description` to the §4.15 sentence; keep it and
  `og:description` identical.
- README: add a short "Social preview" section — what `public/og.png` is
  and `node scripts/make-og.mjs` to regenerate it.
