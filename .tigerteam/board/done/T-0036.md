## Goal
A few boats gliding along the real Thames. OSM has the river centre-line
(`waterway=river`); ship it in the data and reuse the traffic machinery.
Contract already updated (PM): `CityData.rivers?: Vec2[][]` — do not edit
`src/data/types.ts`.

## Context
- Fetch: add `way["waterway"="river"](bbox);` to the Overpass union.
  Converter: emit `rivers` = polylines of those ways (same projection/rounding
  and consecutive-duplicate cleanup as roads; ≥ 2 points; omit the key when
  empty). `.d.ts` needs no change if signatures stay. Fixture: one
  `waterway=river` way. Regenerate `public/data/city.json` (counts within
  ±5 % of `9061 / 7803 / 99 / 31`; expect ≥ 1 river polyline).
- Validator: optional `rivers` — array of polylines with ≥ 2 finite points,
  error path `rivers[i]`; accept/reject cases in `tests/data.test.ts`.
- `src/world/traffic.ts`: add
  `export class BoatFleet { constructor(rivers: Vec2[][], count = 4, seed = 17); readonly object: THREE.Object3D; update(dt: number): void }`
  — walkers ping-pong along a randomly chosen polyline (reverse at the ends;
  no graph), speed 4 m/s. Geometry: `InstancedMesh` of `BoxGeometry(4, 2, 14)`
  at `y = 1.0`, `MeshLambertMaterial({ color: 0xbfc8cc })`, same reused-dummy
  matrix pattern, no per-frame allocation. Reuse `PathWalker` internals where
  sensible (a `reverseAtEnds` option is acceptable — keep existing behaviour
  and tests intact).
- `main.ts`: when `city.rivers?.length`, `BoatFleet(city.rivers)` +
  `scene.add` + `update(dt)` alongside the buses.
- Docs: `docs/world.md` (boats under Traffic), `docs/fetch-osm.md` (rivers).
