## Goal
Fleets take a `HeightFn` and place each instance on it: a bus's matrix y is
`heightAt(x, z) + BUS_HALF_HEIGHT`, a boat's is `heightAt(x, z) + BOAT_Y`.
Defaults keep today's behaviour (`FLAT_HEIGHT` → y = 2.15 / 1.0).

## Context
- `src/world/traffic.ts`: `BusFleet(roads, count = 12, seed = 9, heightAt: HeightFn = FLAT_HEIGHT)`,
  `BoatFleet(rivers, count = 4, seed = 17, heightAt: HeightFn = FLAT_HEIGHT)`.
  Sample `heightAt` in `update()` when writing the dummy position; no
  per-frame allocation (the callback is stored, not wrapped).
- `HeightFn`/`FLAT_HEIGHT` from `src/data/types.ts`. `main.ts` will pass
  `groundAt` to buses and `terrain.heightAt` to boats (T-0045) — not this
  ticket.
