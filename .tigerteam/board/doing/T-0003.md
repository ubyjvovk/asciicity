## Goal
Produce the real dataset: a zero-dependency node script that queries Overpass
for the City of London bbox and converts the result to `public/data/city.json`
per `docs/data-format.md`, plus the committed output of one run.

## Context
- Read `docs/data-format.md` fully — the Overpass query, height rules,
  highway → `cls` mapping, places rules, rounding, and the CLI contract are
  all specified there. `src/data/types.ts` is the shape (you cannot import TS
  from `.mjs`; mirror the shape in JSDoc typedefs).
- Split: `scripts/osm-convert.mjs` exports pure functions
  `convertOverpass(json, {origin}) -> CityData`, `heightOf(tags) -> number`,
  `roadClassOf(highway) -> RoadClass | null`, `project(lon, lat, origin) -> [x, z]`
  (same formulas as data-format.md). `scripts/fetch-osm.mjs` parses CLI args,
  POSTs the query (`fetch`, `Content-Type: application/x-www-form-urlencoded`,
  body `data=` + encodeURIComponent(query)), retries once per endpoint on
  429/504 after 30 s, falls back to the second endpoint, converts, validates
  basic shape, writes minified JSON atomically (write `<out>.tmp`, rename), and
  prints the one summary line from the doc.
- `tsconfig.json` has no `allowJs`, so the TS test importing
  `../scripts/osm-convert.mjs` needs a sibling declaration file
  `scripts/osm-convert.d.ts` (`export function convertOverpass(...)`, etc.,
  typed with the shapes from `src/data/types.ts` via `import type`) or
  `tsc --noEmit` in `scripts/check.sh` fails. Ship it.
- `tests/fixtures/overpass-small.json`: a hand-written Overpass-shaped JSON
  (`{"elements": [...]}`) with: one closed building way with `height: "20 m"`;
  one with `height: "60 ft"`; one with `building:levels: "5"`; one `building=church`
  with no height; one `building:part` way (must be skipped); one open (non-closed)
  building way (skipped); one multipolygon relation with one closed `outer`
  member and one `inner` member; highways of classes primary, secondary_link,
  residential, footway, and `highway=steps` (unmapped → dropped); two place
  nodes with the same name (dedupe) and one station node.
- Network: the Overpass call takes 1–3 minutes for the real bbox. If both
  endpoints fail after retries, do NOT invent data — block with `## Questions`
  (the PM can run the fetch on the host).
- Write `docs/fetch-osm.md`: how to run, what the summary line means, known
  limitations (multipolygon ring assembly not done, inner rings ignored).
