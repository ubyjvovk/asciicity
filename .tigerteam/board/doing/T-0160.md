## Goal
Re-fetch London and Kyiv with the converter from T-0158 so the tiles carry
`roof`, `osmColor`, `roofColor`, `material`. Nothing else may change in
behaviour: same bbox, origin, flags, tiling.

## Context
- Commands (package.json): `npm run fetch-data` (London, tiled) and
  `npm run fetch-data:kyiv` (terrain from `.cache/dem`, may download SRTM).
  Overpass is flaky (504s seen 2026-09-25): the script retries across
  endpoints; if both fail for > 20 min, block with the error text.
- NEVER `cat` the generated JSON (megabytes); inspect with `node -e` / `jq`.
- Before/after: record per city the total tile bytes, building count, and
  the share of buildings with roof / osmColor / roofColor / material.
  Expected (PM Overpass count, ways incl. parts): London roof ≈ 18 % non-flat,
  colours ≈ 31 / 37 %, material ≈ 28 %; Kyiv ≈ 11 / 14 / 10 / 5 %. Big
  deviations (> ×2) → explain in the report.
- Data drift: OSM changed since the last fetch; building counts may differ
  by a few %. That is fine; report it. `applyLandmarks` presets and the
  spawn tests must still pass (they run in check.sh).
- Size guard: if a tile-size guard in the scripts or tests trips, do NOT
  raise it silently — report the numbers and block.
