## Goal
One headless browser test proving the game boots, renders non-black ASCII
output, moves the player, and shows the HUD — and leaves a screenshot the PM
can look at.

## Context
- `docs/architecture.md` §8 (what the smoke test asserts) and §5 (the
  `window.__asciicity` contract exposed by T-0010).
- `@playwright/test` 1.55.1 is already a devDependency; the worker image has
  chromium-1193 at `/opt/pw-browsers` (`PLAYWRIGHT_BROWSERS_PATH` is set in the
  image). Never run `playwright install`.
- `playwright.config.ts`: `testDir: 'e2e'`, `timeout: 60_000`, `retries: 0`,
  `workers: 1`, `reporter: 'list'`, `use: { headless: true, viewport: { width: 1280, height: 720 }, launchOptions: { args: ['--enable-unsafe-swiftshader', '--ignore-gpu-blocklist', '--use-angle=swiftshader', '--disable-dev-shm-usage', '--no-sandbox'] } }`,
  one chromium project, `webServer: { command: 'npx vite --port 4173 --strictPort', url: 'http://127.0.0.1:4173/', reuseExistingServer: false, timeout: 60_000 }`,
  `outputDir: 'test-results'`.
- `e2e/smoke.spec.ts`: goto `/?synthetic=1`; `page.waitForFunction(() => (window as any).__asciicity?.ready === true, undefined, { timeout: 30_000 })`;
  read `state` (x0, z0); click the canvas centre; hold `KeyW` for 600 ms
  (`keyboard.down`/`up`); read `state` again and expect the position to have
  moved ≥ 0.5 m; expect `#hud` text to contain `BEARING` and `ZONE`; compute the
  fraction of non-black pixels by drawing the WebGL canvas onto a 2D canvas in
  `page.evaluate` (sample every 8th pixel) and expect `> 0.02`; save
  `e2e/__shots__/smoke.png` (`mkdir -p` via `node:fs` first; the dir is
  gitignored) with `page.screenshot({ path })`.
- `scripts/check.sh` already runs `npx playwright test` when `e2e/` exists.
- Write `docs/testing.md`: unit vs e2e, how to run each, the chromium flags and
  why, where screenshots land.
