## Goal
Ship San Francisco as the third city: `?city=sf`, picker entry, hills from
SRTM, the Bay via the new coastline rules, Golden Gate Bridge walkable
with international-orange tower extras, and presets for the landmarks.
Dataset spec: `docs/data-format.md` "### San Francisco (`sf.json`,
wave 8)". Read it and the Kyiv precedents (T-0040/T-0045 patterns in
`docs/integration.md`) first.

## Context
- Fetch: `npm run fetch-data:sf` (script already in package.json — do not
  edit package.json). Commit `public/data/sf.json`. Record in the report:
  building/road/water/tree counts, terrain grid size, JSON size, and the
  fetch summary line. If the JSON exceeds 12 MB, STOP and file a blocked
  question instead of committing.
- `src/data/cities.ts`: append `{ id: 'sf', label: 'SAN FRANCISCO',

  Golden Gate · hills & bay' }`.

  `'london' | 'kyiv' | 'sf'` and loosen `presetsFor` to accept `string`
  (keeps `main.ts` untouched — its existing cast still compiles; verify
  `npm run typecheck` without editing main.ts). New presets (`goldengate`

    start from lon −122.4779, lat 37.8170, bearing 160, then VERIFY
    against the fetched bridge way geometry and snap the point onto the
    deck centre-line (a point 30 m off the deck is open water and the
    spawn breaks).
  - `transamerica`, `salesforce` (building 'Salesforce Tower'),
    `coittower` (building 'Coit Tower'), `ferrybuilding` (building
    'Ferry Building'): building presets with coordinate fallbacks like the
    Kyiv ones. VERIFY the exact `name` values against the fetched JSON
