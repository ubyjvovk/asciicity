## Goal
The first synthesised city. Write `scripts/gen-minas-tirith.mjs`, a
deterministic node ESM script that builds the Minas Tirith `city.json`
(seven walled tiers on a 200 m hill, the rock prow, zig-zag gates, ring
roads and the Climbing Way, Pelennor plain, Mindolluin) exactly per
`docs/architecture.md` §4.23 ("Frame", "Tiers", "Terrain", "Walls",
"Roads", the `places` list) and tiles it with the existing tiler. Houses
and landmark buildings are T-0127 — this ticket ships `buildings` = walls +
gate towers only, `trees: []`.

## Context
- Schema: `docs/data-format.md` "Schema (v: 1)" + "Minas Tirith" + the
  "Coordinate system" projection (re-implement `unproject` in JS for the
  `bbox`, as `scripts/osm-convert.mjs` does). Terrain grid rules: the
  "Terrain" section (row 0 = north, `heights` row-major, `datum 0`,

- Structure the script as pure exported functions plus a `main()` guarded
  by `if (process.argv[1] === fileURLToPath(import.meta.url))`, so
  `tests/minastirith.test.ts` can import them (see `tests/tile-city.test.ts`
  for importing an `.mjs`): `TIERS`, `GATE_AZ`, `terrainHeight(x, z,
  rand)`, `buildTerrain(seed)`, `buildWalls()`, `buildRoads()`, `PLACES`,
  `buildCity(seed = 1)` (assembles `{ v: 1, origin, bbox, buildings, roads,
  places, terrain, trees: [] }`), `mulberry32` (copy from
  `src/data/synthetic.ts` — do not import TS).
- Validate the assembled city before tiling with the same rules as
  `src/data/validate.ts` (unique ids, ≥ 3 poly points, finite numbers, h in
  [3, 650]); ring polygons must not repeat the first point last.
- Unit cases (`tests/minastirith.test.ts`), by name:
  1. `terrainHeight`: (0, 0) → 200; (300, 0) → 64 plateau is NOT the answer
     — (300, 0) lies on the east axis inside the prow → 96 (`H_4`); (0, 300)
     → 64; (0, 350 + 12) → between 32 and 64 (ramp); (500, 500) → within
     ±1.5 of 0; (−700, 0) → ≥ 150 (Mindolluin);
  2. prow notch: the point on the east axis at the tier-3 ring road radius
     (`R_3 − 14`, z = 0) → `H_3` (64), not `H_4`;
  3. `buildWalls`: 7 tiers × 48 segments minus gate gaps + 14 gate towers;
     every segment poly has 4 points; L1 segments carry `color 0x2a2a30`;
     the `Great Gate` towers exist with `shape 'tower'`;
  4. `buildRoads`: the main road starts at `(R_1 + 60, 0)`, its vertices are
     monotone non-decreasing in `terrainHeight` after the gate (allow
     ±0.5), and it ends at `(10, 0)`; 7 ring roads; every lane's outer
     vertex is at `R_k − 14`;
  5. `buildCity(1)` twice → deep-equal (determinism) and passes a copy of
     the validation rules; `terrain.cols === terrain.rows === 302`.
- `docs/minas-tirith.md`: what the generator builds, the CLI, the tier
  table, how to regenerate (`npm run gen-data:minas-tirith`), and a note
