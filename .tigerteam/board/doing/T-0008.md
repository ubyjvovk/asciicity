## Goal
Pure movement integration (`stepPlayer`) plus the thin DOM `Controls` class
that turns keys and pointer-lock mouse deltas into an `InputState`.

## Context
- Contract: `docs/architecture.md` §3 (yaw/forward/right/bearing definitions)
  and §4.7 (exports, constants, key map, pointer-lock behaviour). Types from
  `src/data/types.ts` (`Vec2`).
- `stepPlayer` returns a NEW object; never mutates its input. Order: apply
  turn + mouse look, clamp pitch, then move using the updated yaw.
- `Controls`: `keydown`/`keyup` on `window` (ignore auto-repeat), `click` on
  `target` → `target.requestPointerLock()`, `mousemove` accumulates
  `movementX/Y` only while `document.pointerLockElement === target`;
  `readInput()` returns the current state and zeroes the accumulated deltas;
  `dispose()` removes every listener. No top-level side effects (node imports
  the module for tests).
- Write `docs/controls.md` (key map, constants, how to change sensitivity).
