## Goal
The world's perspective floor grid (`world/ground.ts`) shows through the
painterly styles as bright white squares on every open ground (user review:
"squares on the ground everywhere"; PM review of Minas Tirith's Pelennor
and Court of the Fountain). Styles can now opt out: `RenderStyle.groundGrid`
(PM-added, `src/render/style.ts`). Implement the swap per
`docs/architecture.md` §4.11 "Ground grid per style (wave 16b, T-0132)".

## Context
- `src/world/ground.ts`: add `makePlainTexture()` (1×1 canvas, the grid's
  background fill colour — read it from `makeGridTexture`'s `fillRect`),
  `setGroundGrid(mesh: THREE.Mesh, on: boolean): void` (build both textures
  once, cache on `mesh.userData`, swap `material.map`, set
  `material.needsUpdate = true`), and pure `groundGridFor(style: { groundGrid?:
  boolean }): boolean`.
- `src/main.ts`: after the ground mesh is created and after `post` exists,
  call `setGroundGrid(ground, groundGridFor(post.style))`; call it again in
  `applyStyleChange`; expose `api.groundGrid` on `window.__asciicity`.
  Find the ground mesh creation with `grep -n makeGround src/main.ts`.
- `styles/quest.ts` and `styles/lowpoly.ts`: add `groundGrid: false` to the
  style entry (one line each; no other change).
- Tests: `tests/ground.test.ts` (new or extend if it exists): `groundGridFor`
  → true for `{}`, true for `{ groundGrid: true }`, false for `{ groundGrid:
  false }`; the two style modules' entries carry `groundGrid === false` and
  every other registry style resolves to true.
- `e2e/groundgrid.spec.ts` (boot helpers from `e2e/lowpoly.spec.ts`): boot
  `/?synthetic=1&render=quest` → `__asciicity.groundGrid === false`; press
  `R` until `render === 'ascii'` → `groundGrid === true`; and a pixel check:
  in `/?synthetic=1&render=quest&time=12:00` aimed straight down (`aim(page,
  0, -1.4)`), the fraction of near-white pixels (all channels ≥ 200/255) is
  < 0.02 (no grid lines).
- Docs: `docs/render.md` gets a `groundGrid` row in the RenderStyle field
  table; the two style docs mention it.
