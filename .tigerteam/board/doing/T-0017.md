## Goal
Turn on the three wave-2 modules in the running app: the minimap under the
HUD rows, the LANDMARK row fed by `ZoneIndex.nearestLandmark`, and the CRT
overlay, each with a URL switch.

## Context
- `src/main.ts` (T-0010) is the bootstrap; read `docs/integration.md` first.
  Modules: `Minimap` (`src/hud/minimap.ts`, `docs/minimap.md`),
  `ZoneIndex` 4th constructor arg + `nearestLandmark` (`src/hud/zone.ts`,
  `docs/hud.md`), `mountCrt` (`src/render/crt.ts`, `docs/render.md`).
- Changes:
  1. `parseUrlOptions` gains `crt: boolean` (default true; `crt=0` disables)
     and `minimap: boolean` (default true; `minimap=0` disables). Keep it
     exported and pure.
  2. Build `ZoneIndex(city.roads, city.places, 50, city.buildings)`.
  3. Add `<canvas id="minimap">` inside `#hud` in `index.html` (after the
     HUD rows are created by `Hud`, so append the canvas to `#hud` from
     `main.ts` instead if ordering is simpler — either is fine; document
     which). Construct `Minimap(canvas, city)` when enabled; call
     `minimap.update(state)` on the same every-4th-frame cadence as the HUD.
  4. In the HUD update set `hudValues.landmark = zone.nearestLandmark(state.x, state.z, state.yaw)?.name ?? undefined`
     without allocating per frame beyond that call.
  5. `mountCrt(document.body)` when enabled.
  6. `#hud` CSS: allow the minimap canvas below the rows (block, 8 px top
     margin already in `.minimap`); ensure `#hud` stays 320 px wide.
- Update `docs/integration.md` (URL parameter table: `crt`, `minimap`;
  startup sequence) and the README "How to play" params list.
- Verify visually as in T-0010 (throwaway Playwright script, not
  committed; `page.mouse.move(640,360)` before clicking): describe the
  minimap, LANDMARK row and overlay in the report.
