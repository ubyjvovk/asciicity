## Goal
A secret toggle: pressing `G` (or loading with `?gloom=1`) flips the scene to
a bright-grey sky with dark, desaturated glyphs — London on an overcast day.
Default stays the black cyberspace look.

## Context
- `AsciiRenderer` (`src/render/ascii.ts`, contract architecture.md §4.8).
- Shader change — extend the fragment shader with a uniform `invert`
  (float 0/1) and replace the final line:
  ```glsl
  vec3 normalCol = tint * mask;
  float lumT = dot(tint, vec3(0.299, 0.587, 0.114));
  vec3 washed = mix(vec3(lumT), tint, 0.35) * 0.35;   // dark, desaturated glyphs
  vec3 gloomBg = vec3(0.72, 0.73, 0.75);              // bright grey sky
  vec3 gloomCol = mix(gloomBg, washed, mask);
  gl_FragColor = vec4(mix(normalCol, gloomCol, invert), 1.0);
  ```
  Glyph density (`idx`) is unchanged, so empty cells become solid grey in
  gloom mode (mask 0 → background) — that is the intended look.
- API: `AsciiOptions` gains `invert: boolean` (default false);
  `setInvert(on: boolean): void` updates the uniform; `get invert(): boolean`.
  Mirror helper for tests: `export function gloomMix(tint: [number, number, number], mask: number, invert: number): [number, number, number]`
  implementing exactly the four lines above (pure).
- `main.ts`: `parseUrlOptions` gains `gloom: boolean` (`gloom=1`); pass
  `invert` to the `AsciiRenderer` options; `keydown` listener for `code === 'KeyG'`
  (ignore repeats) toggling `ascii.setInvert(!ascii.invert)`.
- Docs: `docs/render.md` (gloom section + the shader block updated — quote it
  verbatim), `docs/integration.md` (URL table `gloom`, key list `G`).
- **PM-owned `docs/architecture.md` §4.8 is intentionally NOT in scope** —
  flag in your report that the PM must sync the doc shader after accept.
