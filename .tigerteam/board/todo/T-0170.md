## Goal
The user asked for proper cars in cyberpunk: Corvette C6, Porsche 911,
Land Cruiser FJ40, Skyline GT-R R32, big US sedans (Crown Victoria taxi +
police, Lincoln Town Car), top-line Toyota (Century), plus lore picks
(DeLorean, Countach, 300ZX). The PM downloaded, simplified and committed
them: `public/models/cars/` (`manifest.json`, `<id>.lod0.glb` /
`<id>.lod1.glb`, `CREDITS.md`). Draw the existing traffic fleet with
these models in the cyberpunk style. The design is LOCKED in
docs/architecture.md §4.11 "Vehicles — real car models in cyberpunk
(wave 23c, T-0170)" — read it and the `PunkLayerContext.traffic()` JSDoc in
`punk/layer.ts` first.

## Context
- `ctx.traffic()` returns the CarFleet InstancedMesh (`src/world/traffic.ts`):
  instance matrices updated every frame; boxes centred at ground +
  `CAR_HALF_HEIGHT`, rotation.y = −heading. Import the constants from
  traffic.ts (read-only).
- Models come in WILDLY different units and orientations (measured by the
  PM): bbox sizes range 0.02 m to 199 m; most have their length along z,
  the Town Car along x (manifest `yaw` = π/2). Normalise per manifest:
  apply `yaw`, scale so the bbox extent along z = `length`, origin at the
  bbox bottom-centre. The FORWARD direction (+z vs −z) is not verified —
  the PM will check in-game and flip `yaw` by π in the manifest if needed;
  your code must just honour `yaw`.
- Some models lack normals (the simplifier dropped them) — call
  `computeVertexNormals()` when absent. Some have no textures (Century is
  flat grey) — the paint rule (§4.11) applies to the largest-area material.
- GLTFLoader: `import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js'`
  (allowed in punk/). Textures are WebP (EXT_texture_webp is supported by
  GLTFLoader). Load lazily when the layer first attaches; while loading,
  keep drawing the fleet boxes (do not hide them until models are ready).
- Register the layer in `layers.ts` after `props` (`layers.ts` is PM-owned
  but this ticket may add exactly that one line + import).
- Pure `vehiclemath.ts` (no three/webgpu import): weighted stable model
  pick `pickModel(i, weights)`, LOD choice `lodFor(distance)`, normalisation
  maths (`normaliseTransform(bbox, yaw, length)` → { scale, offset }),
  light-anchor derivation from a bbox.
- Performance (the user is on a MacBook): instanced draws only; no
  per-car Object3D; no allocation per frame; update matrices only for cars
  whose LOD bucket is visible.
- **Never open or read any `.png` / `.jpg` / `.glb` as an image.**
