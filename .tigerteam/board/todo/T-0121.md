## Goal
A Playwright spec that proves the `lowpoly` style (T-0120,
`docs/architecture.md` §4.11 "`lowpoly` (wave 15)") really renders flat
palette facets with ink outlines, by measuring pixels — the same way
`e2e/amber.spec.ts` proves the amber look.

## Context
- New file `e2e/lowpoly.spec.ts`. Copy the boot helpers (`waitReady`,
  the offscreen-canvas pixel sampler) from `e2e/amber.spec.ts`; never
  edit `smoke.spec.ts` or `amber.spec.ts`.
- URL: `/?synthetic=1&render=lowpoly&cell=6x6&time=12:00`. After ready +
  two double-rAF waits, sample the `#view` canvas via `drawImage` +
  `getImageData` in-page, exactly like `amber.spec.ts`.
- Build the expected colour set in the spec from the style's pure
  exports: `import { LOWPOLY_HUES, LOWPOLY_LUM, LOWPOLY_INK } from
  '../src/render/styles/lowpoly'` — the set is every `hue × lum` and
  `[1,1,1] × lum` combination, plus `LOWPOLY_INK` and black.
- Assertions:
  1. non-black fraction > 0.02 (it renders at all);
  2. palette purity: ≥ 0.90 of all pixels are within 12/255 per channel
     of some colour in the expected set;
  3. outlines present but not dominant: the fraction of pixels within
     12/255 of `LOWPOLY_INK` (or black) is between 0.02 and 0.60;
  4. at least 3 distinct non-grey hues appear, each on ≥ 0.5 % of pixels
     (the synthetic city has many building colours; the look must not
     collapse to one hue).
- If a threshold fails by a small margin, report the measured numbers in
  the Worker report and adjust the threshold only within: purity ≥ 0.85,
  ink 0.01–0.70, hues ≥ 2. Anything worse means the shader (T-0120) is
  wrong — block with a `## Questions` entry instead of loosening further.
