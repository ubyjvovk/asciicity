## Goal
The Golden Gate Bridge roadway is `highway=motorway` (OSM ways 537838948,
595194543, 1321812310; `bridge=yes`, 3–4 lanes) and the converter drops it,
so the bridge is only its two sidewalks. Map `motorway` and `motorway_link`
to `cls: 'primary'` (contract: `docs/data-format.md` "Roads — highway
mapping", wave-9 note) and re-fetch `public/data/sf.json` so the deck
carries a road (and buses).

## Context
- `scripts/osm-convert.mjs` `ROAD_CLASS` (≈ line 49): add `motorway:
  'primary'`, `motorway_link: 'primary'`. The `bridge` handling for mapped
  classes already exists (`bridge: true` when `bridge≠no`).
- `scripts/fetch-osm.mjs` line ≈ 45 builds the Overpass `highway` regex —
  add `motorway|motorway_link` to it (same regex is quoted in
  data-format.md; the PM already updated the prose there — do not edit
  data-format.md).
- Re-fetch: `npm run fetch-data:sf`. Guard: if the JSON exceeds 16 MB stop
  and file a blocked question. Expect ≈ +0.1 MB over the committed
  14 638 126 bytes. Record the fetch summary line and the counts in the
  report. Do NOT re-fetch London/Kyiv (their bboxes hold no motorways;
  their files must not change).
- NEW `tests/sf-data.test.ts`: read `public/data/sf.json` (see how
  `tests/landmarks.test.ts` loads it) and assert: at least one road named
  exactly `Golden Gate Bridge` with `cls === 'primary'` and `bridge ===
  true`; every such road's points fall inside the sf bbox; the two sidewalk
  roads still exist (`Golden Gate Bridge East Sidewalk` / `West Sidewalk`,
  `pedestrian`, `bridge: true`).
- `tests/osm-convert.test.ts`: add a unit case that a `motorway` way with
  `bridge=yes` converts to `cls: 'primary', bridge: true`, and
  `motorway_link` to `primary`.
- `docs/integration.md`: update the SF counts sentence if present; one line
  noting the roadway is now a `primary` bridge road.
