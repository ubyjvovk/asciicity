## Goal
Huge container ships steaming through the Golden Gate and past Alcatraz,
plus a dozen sailboats between the Marina and Alcatraz, all with their
lights on at night. Contract: `docs/architecture.md` §4.17 — read it in
full first; lanes, dimensions, colours, class surface and the night rule
are the spec.

## Context
- NEW `src/world/ships.ts` with exactly the §4.17 surface (`ShipLane`,
  `SHIP_LANES`, `ShipFleet`). Motion: reuse `PathWalker` + `buildRoadGraph`
  from `src/world/traffic.ts` exactly as `BoatFleet` does (isolated
  polylines, `reverseAtEnds = true`, `mulberry32(seed + i)`); per-lane speed
  (cargo 6 m/s, sail 3 m/s). Projection: the `project(lon, lat, origin)`
  helper used by `landmarks.ts`.
- Meshes: build each class's hull as one `MeshData` via `MeshBuilder` (box
  helper: six faces, outward normals, linear rgb colours) → `toGeometry` →
  `THREE.InstancedMesh(geometry, new THREE.MeshLambertMaterial({
  vertexColors: true }), n)`. Lights: a second `MeshData` of small bright
  boxes → `InstancedMesh` with `MeshBasicMaterial({ vertexColors: true })`
  (unlit, so the ASCII pass renders them as hot cells). `update(dt)` writes
  the same matrix into both meshes (`setMatrixAt` twice); `object` is a
  `THREE.Group` of the (up to) four meshes; a city without lanes → `count
  0`, empty Group, no-op update.
- Water height: instance `y = heightAt(x, z)` with `heightAt =
  terrain.heightAt` (flattened Bay) — same as `BoatFleet` in `main.ts`
  (≈ line 429); hull geometry is authored with the waterline at local
  y = 0.
- `src/main.ts`: construct `const ships = new ShipFleet(cityId ??
  'synthetic', city, terrain ? terrain.heightAt : FLAT_HEIGHT)` next to the
  boats, `scene.add(ships.object)`, call `ships.update(dt)` beside
  `boats?.update(dt)`; night: in the existing 10 s sky `setInterval` (≈ line
  438) and once right after it, `ships.setNight(sunPosition(opts.time ??
  new Date(), city.origin.lat, city.origin.lon).altitudeDeg < -6)`
  (`sunPosition` is exported from `src/world/sky.ts`; check its argument
  order). Expose `ships: { count, lightsOn }` on `window.__asciicity`
  (getter-style so `lightsOn` is live). Touch nothing else in main.ts.
- `tests/ships.test.ts` (node, no WebGL — test the pure parts: lane
  projection, `MeshData` construction, walkers; construct `ShipFleet` only if
  `InstancedMesh` works headless — it does, three creates no GL objects
  until render): `'every SF lane vertex lies on water (odd parity over
  sf.json rings)'` (use `pointInPolygon` from `src/world/collision.ts`),
  `'SF fleet has 15 ships: 3 cargo + 12 sail'`, `'London and Kyiv fleets
  are inert (count 0, update is a no-op)'`, `'setNight toggles the lights
  meshes visible flag and lightsOn'`, `'cargo hull spans 280 × 40 m with
  the waterline at y 0'` (from the MeshData bounds), `'update advances
  ships without allocating per frame'` (positions change; heading finite).
- NEW `e2e/ships.spec.ts` (never edit smoke.spec.ts / sf.spec.ts): boot
  `/?city=sf&at=pier39&time=22:30` → ready, `__asciicity.ships.count ===
  15`, `lightsOn === true`; boot `/?city=sf&at=pier39&time=12:00` →
  `lightsOn === false`. 90 s ready timeout (pattern: `e2e/sf.spec.ts`).
- `docs/integration.md`: "Bay shipping" note under the SF section (lanes
  table location, how to add a lane, night rule).
