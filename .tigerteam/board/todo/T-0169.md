## Goal
T-0168 (your v2, accepted) placed the right number of signs at eye level,
but the PM GPU review from the Shinjuku spawn still does not read as
"a bunch of cyberpunk neon": the spawn is a wide plaza, facades are 30+ m
away, and 0.8–1.2 m wide blades are a few pixels at that distance. Real
Shinjuku/Kabukicho signs are BIG and seen from narrow streets. v3 = scale +
density + the right vantage points. Tokyo only unless stated.

## Changes (numbers are the contract; PM updates §4.11 on accept)
1. **Scale with building height** (tokyo): blades width `clamp(0.9 + h/40, 0.9, 2.2)` m,
   height `clamp(3 + h/6, 3, 10)` m (bottom stays in [3, 7] m); stack panels
   `1.6 × 0.9` → `clamp(1.6 + h/50, 1.6, 2.8) × 0.9–1.4`; panels width 3–9 m;
   screens unchanged. Default profile keeps v2 sizes.
2. **Density** (tokyo): `p = 1.0`, cap `min(10, 3 + floor(h / 12))`, road reach
   20 m (default profile keeps 12 m, so London's output only changes if it
   must — say so if the shared code forces it).
3. **Glow**: glow cards 3.0 × the sign size (was 2.2), colour × 0.45.
4. **Presets**: add `kabukicho` (on Kabukicho Ichibangai, the street under
   the red gate, facing north into it) and `centergai` (Shibuya Center Gai,
   facing north-west up the street). Pick a road VERTEX from the Tokyo tile
   data (never type coordinates from memory): find the OSM road named
   (en or ja) "Ichibangai"/"一番街" near (−5850, −1250) and "Center Gai"/
   "センター街" near (−5950, 2500) — verify the names in the data, report
   the vertex, bearing, and the number of v3 signs within 60 m with bottom
   ≤ 10 m. Follow the existing preset conventions + walkability tests.
