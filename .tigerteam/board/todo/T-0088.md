## Goal
Manhattan's East River bridges start at street level on both banks, so the
straight abutment-to-abutment lerp puts the Brooklyn Bridge deck ~3 m over
the river (T-0087 report, note 1); the real deck is 41 m ASL at mid-span.
Add deck humps driven by the bridge spec, generalise the spec to
one-walkway bridges, build the three NYC structures, and move
`brooklynbridge` to true mid-span. Contracts: `docs/architecture.md` §4.9
"Deck humps (wave 10)" and §4.16 (`sidewalks: [string] | [string,
string]`, `deckWidth`, `deckApexASL`, `deckRoads`, `deckHumps`, the
one-walkway frame rule) — read both in full first.

## Context
- `src/world/terrain.ts`: `DeckHump`; `bridgeProfile(pts, heightAt,
  apexY?)` — with `apexY`, `ys[i] = max(terrain, q(t_i))` where `q` is the
  quadratic through `(0, ya)`, `(0.5, apexY)`, `(1, yb)`; without it,
  unchanged. `BridgeDecks(roads, heightAt, cell = 25, humps = [])`: after
  `chainBridgeRoads`, a road whose `name` is in a hump's `names` uses that
  hump's `apexY`.
- `src/world/roads.ts`: `buildRoadsMesh(roads, heightAt, humps = [])` /
  `makeRoadsObject(roads, heightAt, humps = [])` — same lookup.
- `src/world/bridge.ts`: spec fields `deckApexASL`, `deckRoads`,
  one-walkway `sidewalks: [name]` + `deckWidth` (frame rule in §4.16);
  `export function deckHumps(cityId, city): DeckHump[]`; SF spec gets
  `deckApexASL: 67, deckRoads: ['Golden Gate Bridge']`; NYC specs:
  Brooklyn Bridge (walkway `Brooklyn Bridge Promenade` — verify the exact
  name(s) in nyc.json; one walkway, `deckWidth` 26, towers 84 m above water
  → `towerTopAboveDeck` ≈ 43, `sideSpan` 284, granite `0x8f857a`,

  Manhattan Bridge (`Manhattan Bridge Pedestrian Path` + the north bike
  path if present as a bridge road, else one walkway with `deckWidth` 37;
  towers 102 → 61; `sideSpan` 221; `0x6f7f8f`; apex 41), Williamsburg
  Bridge (walkway(s) from the data; `deckWidth` 36; towers 94 → 54;

- `src/main.ts`: `const humps = deckHumps(cityId ?? 'synthetic', city)`;
