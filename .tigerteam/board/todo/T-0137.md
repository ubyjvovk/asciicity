## Goal
User review of `scribble` v2: "looks like it has a fixed grid overlay of
irregular lines that looks out of place". The strokes are drawn in screen
space, so the pattern stays put while the world slides under it. v3 anchors
every stroke to the world and keeps the on-screen spacing constant with a
nested power-of-two level of detail; the sky tangle sticks to the sky dome.
Every formula is locked in `docs/architecture.md` §4.11, subsection
"`scribble` v3 (T-0137)" — read it first; it is the contract. Colour,
outline, tone, thresholds, half-widths, lifts and the ground/wall class
rule stay exactly as v2.

## Context
- Edit `src/render/styles/scribble.ts` in place; keep the exported `STYLES`
  shape and every v2 export the spec does not delete. `strokeInk` is
  deleted; new pure exports: `strokeCoords(W, nW, dC, up): { u, along }`,
  `lodOf(m): { L, f }`, `nestedStrokeInk(u, along, tone, m)`,
  `skyCoords(dirW, K): [x, y]`; `hash2` is replaced by the v3 hash.
- `viewToWorld` (mat4) is a new common uniform already declared in
  `STYLE_PRELUDE` (`src/render/style.ts`, read the header comment for the
  position / direction formulas); `post.ts` copies the camera's
  `matrixWorld` into it every frame. Never redeclare prelude uniforms.
- Strokes are per PIXEL: `P = viewPos(vUv, dC, …)` with the continuous
  `vUv` and the cell's depth `dC`; the class, the normal and the outline
  stay per cell exactly as v2.
- GLSL: the three layers are a constant-bound loop or an `if` ladder as
  before; `exp2`, `log2`, `mod`, `atan(y, x)`, `asin` are all GLSL ES 1.0.
  Use `highp float` (the prelude sets it). Compute `S = exp2(float(j))`
  with `j = L − k` as a float.
- Unit tests (`tests/styles/scribble.test.ts`): keep every v2 case that
  still applies (`depthFade`, `tangleInk`, `viewPos`, `viewNormal`,
  `surfaceClass`, `skyDensity`, `inkColour`, `washColour`); rewrite the
  `hash2` case for the v3 hash (deterministic, in `[0, 1)` for 200 pairs
  including world-sized values like `(5123.7, 61)`); delete the
  `strokeInk` cases; add, by name:
  1. `strokeCoords` — wall with world normal `[1, 0, 0]` at `W = [3, 7,
     11]`, `dC = 20`, `up = 0`: `u = ±11` (abs 11), `along = 7`; ground
     (`up = 1`) at the same `W`: `u = 20`, `along = 14`;
  2. `lodOf(0.125)` → `{ L: 0, f: 0 }` (8·0.125 = 1 m); `lodOf(0.25)` →
     `{ L: 1, f: 0 }`; `lodOf(0.1875)` → `L: 0`, `f ≈ 0.585` (toBeCloseTo, 3);
  3. `nestedStrokeInk(u, along, 0, m)` → 0 on a 64 × 64 grid (`u`, `along`
     in metres at 0.05 m steps, `m = 0.02`); every value at tone 1 in `[0, 1]`;
  4. density grows with tone: the grid mean is strictly increasing across
     tones `[0, 0.2, 0.5, 0.8, 1]` at `m = 0.02`;
  5. no pop: for tone 1 and 200 random sample points (seeded), the value
     at `m = 2^j·(1 − 1e−4)` and at `m = 2^j·(1 + 1e−4)` (for `j = −3` and
     `j = −2`) differs by < 0.05;
  6. depth-independent density: the grid mean at tone 1 (grid spanning
     `u`, `along` ∈ [0, 64·m), step m) for `m ∈ {0.01, 0.02, 0.05}` is
     within ±35 % of the mean of the three;
  7. `skyCoords([0, 0, −1], 100)` → `[0, 0]`; `skyCoords([0, 1, 0], 100)`
     → y ≈ 157.08 (π/2·100); `skyCoords([1, 0, 0], 100)` → x ≈ 157.08.
- `docs/styles/scribble.md`: replace the stroke step with the world
  anchoring + nested LOD, the sky step with the dome coordinates, update
  the pure-exports list and the common-uniforms table (add `viewToWorld`).
- **Never read, open or view any `.png`** (image input kills non-vision
  engines and the attempt is lost); `ls -la` is all you may do. The PM
  does the visual review, including the "strokes move with the world"
  check.
