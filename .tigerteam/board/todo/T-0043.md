## Goal
Every world builder accepts a `HeightFn` and drapes its geometry over it,
per `docs/architecture.md` §4.2 (buildings: base = min, roof = max + h) and
§4.5 (roads: 10 m sub-segments with per-corner heights, bridge decks from
`bridgeProfile`, `ROAD_LIFT = 0.15`; water: `levels[i] + 0.3`). With the
default `FLAT_HEIGHT` the output is the old flat world (roads rise from
0.05 to 0.15 — update the existing assertion).

## Context
- Read §4.2 and §4.5 of `docs/architecture.md` (updated 2026-08-26) and
  `docs/terrain.md` (landed by T-0042). Import `bridgeProfile` from
  `src/world/terrain.ts`; `HeightFn`/`FLAT_HEIGHT` from `src/data/types.ts`.
- Signatures (keep existing positional params, add trailing optionals):
  `buildBuildingsMesh(buildings, heightAt = FLAT_HEIGHT)`,
  `makeBuildingsObject(buildings, windowTex, heightAt = FLAT_HEIGHT)`,
  `buildRoadsMesh(roads, heightAt = FLAT_HEIGHT)`, `makeRoadsObject(roads, heightAt = FLAT_HEIGHT)`,
  `buildWaterMesh(rings, levels?)`, `makeWaterObject(rings, levels?)`;
  export `ROAD_LIFT`.
- Roads: sub-segment count `n = max(1, ceil(len / 10))`; for ordinary roads
  sample `heightAt` at each of the four quad corners (left/right offsets
  included); for `bridge: true` roads the deck height at fraction `f` along
  polyline segment `i` is `lerp(ys[i], ys[i+1], f)` with
  `ys = bridgeProfile(road.pts, heightAt)`, identical for both edges.
- Buildings: `base = min`, `top = max` of `heightAt` over ring vertices;
  walls `base … top + h`, wall `v = (y − base) / 24`, roof at `top + h`.
- Docs: `docs/world.md` (buildings + water sections), `docs/roads-ground.md`
  (roads) — describe the new parameters and the rules.
