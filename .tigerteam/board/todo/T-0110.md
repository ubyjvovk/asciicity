## Goal

Fetch and commit the tiled Sydney dataset (harbour, CBD, Opera House,
Harbour Bridge, North Sydney), register it in the city picker, and prove it
boots with a smoke e2e. This is the project's first southern-hemisphere city
(DEM tile `S34E151`) and it uses the bare-earth DEM filter.

## Context

- **The contract is `docs/data-format.md` "### Sydney"** — bbox, origin,
  command, size budget, S-hemisphere notes, `--dem-bare` rationale. Read it
  first; it is authoritative.
- Fetch command: `npm run fetch-data:sydney` (alias already committed in
  `package.json`). Overpass etiquette as in T-0097: on a 429/504, back off
  and retry; `--chunks 2x2` splits the load.
- The PM already live-verified `hgtTileName`/`fetchDemTiles`/`elevationAt`
  for `S34E151` (2026-08-31 probe) — no `scripts/dem.mjs` change is
  expected. Your job is the end-to-end confirmation via the dataset
  transect below.
- The harbour is `natural=coastline` (wave-8 machinery, like SF Bay).
  Fort Denison and Goat Island are closed coastline rings (islands).
- Registry pattern: `src/data/cities.ts` `CITIES` — copy the tokyo entry
  shape. Append AFTER tokyo (array order = picker order). No
  `defaultRender` for Sydney. `sizeBytes` = byte size of the committed
  `public/data/sydney/index.json` (`stat -c %s`).
- Spawn preset pattern: `src/data/spawn.ts`. Add `'sydney'` to the
  `SpawnPreset` `city` union type, and ONE coordinate preset:
  `circularquay: { lon: 151.2110, lat: -33.8613, bearingDeg: 0, label:
  'CIRCULAR QUAY', city: 'sydney' }`. (Wave-14 ticket T-0111 adds the full
  preset list later — do not add more.)
- e2e pattern: copy `e2e/tokyo.spec.ts` / `e2e/nyc.spec.ts`. A 90 s ready
  timeout is allowed (SF precedent). Use the memoized dataset-test helpers
  (`tests/tiledCity.ts`) for any unit test that reads the tiles — CI
  runners are slow on I/O (T-0101 lesson).

## Acceptance criteria

- [ ] `npm run fetch-data:sydney` completed against live Overpass; the
      committed output is `public/data/sydney/index.json` + tile files,
      validator-clean (the fetch pipeline runs `validateCity`).
- [ ] **Size guard**: index + tiles total ≤ 12 MB. If over, STOP and file a
      blocked question with the byte breakdown — do not trim data yourself.
- [ ] **S-hemisphere transect (report the numbers in the Worker report)**:
      from the committed terrain via `unproject`/`Terrain` — Circular Quay
      origin ASL in [0, 10]; Observatory Hill (151.2043, -33.8587) in
      [12, 40]; North Sydney ridge (151.207, -33.839) in [45, 85]; Mrs
      Macquarie's Point (151.222, -33.8587) in [0, 12]; the main harbour
      water ring's `waterLevel` ≤ 3 m ASL. Absolutes are sanity bounds; if
      one fails, investigate before touching any bound (wave-13a lesson —
      flatness/deltas are gates, absolutes only catch sign/tile errors: a
      hemisphere bug would show as wildly wrong or mirrored heights).
- [ ] Tile invariants (report): tile count, total bytes, largest tile,
      zero `bridge: true` roads inside tiles (bridge roads are global in
      `index.bridgeRoads`).
- [ ] `src/data/cities.ts`: sydney entry as specified in Context (id
      `sydney`, label `SYDNEY`, defaultSpawn `circularquay`, `tiled: true`,
      real `sizeBytes`, blurb mentioning the harbour/Opera House/bridge).
- [ ] `src/data/spawn.ts`: `'sydney'` in the city union + the single
      `circularquay` preset, nothing else.
- [ ] `e2e/sydney.spec.ts`: boots `/?city=sydney`, reaches CLICK TO ENTER,
      HUD rows render including ALT (terrain city), player moves ≥ 0.5 m,
      ZONE row non-empty.
- [ ] **Report for the follow-up tickets** (they bind by exact name):
      (a) bridge road names crossing the harbour at the Harbour Bridge —
      confirm presence + piece counts of `Bradfield Highway`,
      `Cahill Walk`, `Harbour Bridge Cycleway` in `index.bridgeRoads`;
      (b) any `bridge:support`/pylon building footprints near both bridge
      ends, with local-coordinate centroids;
      (c) Opera House massing — the `Sydney Opera House` building (relation
      outline) h + count/max-h of `building:part`s on Bennelong Point;
      (d) `Sydney Tower` part present with h ≈ 270 (y/n, actual h).
- [ ] `docs/data-format.md` "### Sydney": fill the "Shipped counts" line
      (buildings / roads incl. bridge roads / places / water / rivers /
      trees / landmarks, terrain dims + datum, tile count, byte totals).
- [ ] `bash .tigerteam/scripts/run-tests.sh` exits 0 (full suite).
- [ ] No files changed outside scope.
