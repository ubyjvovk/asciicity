## Goal
One key gives the player an artifact that lives outside the tab: `P` (and a
pause-menu button for touch) downloads the current frame as a PNG with a
28-px caption bar. `docs/architecture.md` §4.15 is the contract — read it
first. This ticket is the PNG half; `recordGif` is T-0073 (do NOT implement
it — leave it out of the interface for now).

## Context
- New module `src/export/postcard.ts` exactly per §4.15: `createPostcard`,
  `afterRender()` hook, `snapPng(download = true)`. The WebGL canvas is not
  preserved between frames, so the copy (`drawImage` onto an offscreen 2d
  canvas) MUST happen inside `afterRender()`, which `main.ts` calls
  immediately after `post.render(scene, camera)` in `frame()` (~line 930).
  `snapPng` sets a pending flag and resolves from the next `afterRender`.
- Caption bar constants (colours, font, layout) live in §4.15. City label:
  upper-cased city label from the registry (`src/data/cities.ts`); the
  meta callback in `main.ts` closes over the loaded city.
- Key: extend the existing `keydown` listener in `main.ts` (~line 859,
  where `R`/`H`/`M` live): `KeyP` without shift → `snapPng()`. Ignore
  repeats (already handled). `Shift+P` is reserved for T-0073 — no-op now.
- Pause menu: add a `SAVE PNG` `menuButton` directly under the `STYLE:` row
  (see `menuButton(...)` uses around `src/main.ts:749–780`): dismiss the
  overlay exactly the way CLICK TO RESUME does, wait two
  `requestAnimationFrame`s, then `snapPng()`.
- Toast `POSTCARD SAVED` (existing `toast.show`).
- Test hook per §4.15: `window.__asciicity.postcard('png')` → Promise<Blob>
  without download ('gif' rejects until T-0073).
- Help line (`src/hud/hud.ts`): insert `P POSTCARD` before `ESC MENU`;
  document the key in `docs/hud.md`.
- Pure + unit-tested in `tests/postcard.test.ts`:
  `postcardFilename('london', new Date(2026, 7, 28, 14, 22, 33))` ===
  `'asciicity-london-20260828-142233.png'` (zero-padded, local time); the
  caption layout helper (given width → bar rect + left/right text
  positions).
- e2e in NEW file `e2e/postcard.spec.ts` (copy the boot/ready helpers from
  `smoke.spec.ts`; never edit smoke.spec.ts):
  1. `/?synthetic=1&cell=3x6`: `__asciicity.postcard('png')` resolves; blob
     bytes start with the 8-byte PNG magic; IHDR width === canvas width and
     height === canvas height + 28.
  2. Pressing `P` fires a `download` event with
     `suggestedFilename()` matching `/^asciicity-\w+-\d{8}-\d{6}\.png$/`.
  3. Touch viewport 390×844 (see the gear-menu e2e in smoke.spec.ts for
     the pattern): tap `#gear` → tap `SAVE PNG` → `download` event fires.
