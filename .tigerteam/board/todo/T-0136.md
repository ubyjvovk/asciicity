## Goal
Apply the PM's GPU review of `scribble` v1 (T-0134). Four locked changes in
`docs/architecture.md` §4.11, subsection "`scribble` v2 (T-0136)" — read it
first; it is the contract: (1) classify ground/wall from the **view-space
normal** (`viewUp`, `tanHalfFov` — new common uniforms already in
`STYLE_PRELUDE`) with **clamped** depth taps, replacing the vertical-slope
rule (v1 turned walls horizontal when looking up and drew vertical ticks
on the bottom pixel row); (2) wash 0.30 → 0.14; (3) ink `mix(INK,
tint·0.50, 0.85·satF)`; (4) sky family-0 spacing 2.5, density
`mix(0.60, 0.30, daylight)`, surface wobble first term 0.50.

## Context
- Edit `src/render/styles/scribble.ts` in place; keep the exported `STYLES`
  shape and every v1 export that v2 does not replace. `SLOPE_K` and the v1
  `surfaceClass(dC, dU, dD, far)` are **deleted**; new pure exports:
  `viewPos(uv: [x, y], d, tanHalfFov, aspect): [x, y, z]`,
  `viewNormal(uvs: { L, R, U, D }, depths: { L, R, U, D }, tanHalfFov,
  aspect): [x, y, z]` (unit), `surfaceClass(dC, far, up): 0 | 1 | 2`
  (`up = |dot(n, viewUp)|`), `UP_K = 0.6`. Update the JSDoc of anything
  whose formula changed.
- Read `src/render/style.ts` (the prelude now declares `viewUp` and
  `tanHalfFov`; the header comment gives the view-space position formula)
  and `src/render/post.ts` `worldUpInView` (how `viewUp` is produced).
  Never redeclare prelude uniforms.
- In the shader the taps' uvs are clamped to `[0.5·texel, 1 − 0.5·texel]`
  BEFORE sampling; use the clamped uvs in `viewPos` too, so the bottom /
  edge rows get a real (one-sided) normal instead of an off-texture value.
- Unit tests (`tests/styles/scribble.test.ts`): keep the v1 cases that
  still apply (hash2, depthFade, strokeInk, tangleInk, inkColour,
  washColour — update the numeric expectations that changed: wash tone-1
  is still `r > b`; `inkColour([1, 0.2, 0.2])` now has `r ≈ 0.50·0.85 +
  0.12·0.15 = 0.443`), delete the slope cases, and add, by name:
  1. `viewPos([0.5, 0.5], 10, 0.7002, 16/9)` → `[0, 0, −10]`;
     `viewPos([1, 0.5], 10, 0.7002, 16/9)` → x ≈ 12.448, z = −10;
  2. `viewNormal` of a **floor** — camera 1.7 m up, level, taps at
     texel-centre uvs around uv (0.5, 0.3) with depths from the analytic
     ground `d(uv) = 1.7 / ((0.5 − uv.y)·2·tanHalfFov)` → `|n.y| > 0.95`;
  3. `viewNormal` of a **frontal wall** — every tap at d = 30 → n ≈ (0, 0, 1)
     (up to sign), `|n.z| > 0.99`;
  4. `surfaceClass(1970, 2000, 1)` → 0; `surfaceClass(30, 2000, 0.98)` → 1;
     `surfaceClass(30, 2000, 0.05)` → 2; `surfaceClass(30, 2000, 0.6)` → 2
     (strictly greater than `UP_K` is ground);
  5. sky density: export `skyDensity(daylight)` and assert `skyDensity(0)`
     → 0.60, `skyDensity(1)` → 0.30 (toBeCloseTo, 6).
- `docs/styles/scribble.md`: update the class step, the colour constants,
  the tangle numbers, the pure-exports list and the uniforms table (add
  `viewUp`, `tanHalfFov` as *common* uniforms read).
- **Never read, open or view any `.png`** (image input kills non-vision
  engines and the attempt is lost); `ls -la` is all you may do. The PM
  does the visual review.
