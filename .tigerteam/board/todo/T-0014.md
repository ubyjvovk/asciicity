## Goal
A small heading-up minimap drawn on a 2D canvas: nearby building footprints,
roads, the player as an arrow at the centre, and a north marker. This ticket
delivers the module + tests only; wiring into `main.ts` is a later ticket.

## Context
- Coordinate system: `docs/architecture.md` §3 (x east, z south, yaw 0 = north,
  forward = `(sin yaw, −cos yaw)`). Types: `src/data/types.ts`,
  `PlayerState` from `src/player/controls.ts`.
- Exports (exact):
  ```ts
  export interface MinimapOptions { size: number /* canvas px, default 180 */; radius: number /* metres centre→edge, default 160 */; headingUp: boolean /* default true */ }
  export function worldToMinimap(px: number, pz: number, player: { x: number; z: number; yaw: number }, opts: MinimapOptions): [number, number]
  export class Minimap {
    constructor(canvas: HTMLCanvasElement, city: CityData, opts?: Partial<MinimapOptions>)
    update(player: { x: number; z: number; yaw: number }): void
  }
  ```
- `worldToMinimap`: `dx = px − player.x`, `dz = pz − player.z`; when
  `headingUp`: `rx = dx·cos(yaw) + dz·sin(yaw)`, `rz = −dx·sin(yaw) + dz·cos(yaw)`
  (so the player's forward vector maps straight up); else `rx = dx`, `rz = dz`.
  `k = (size / 2) / radius`; result `[size/2 + rx·k, size/2 + rz·k]`.
- Constructor buckets building footprints and road segments into a 100 m cell
  grid once (same pattern as `ZoneIndex` in `src/hud/zone.ts`); `update`
  gathers the cells within `radius` of the player, then draws: black
  background; roads as 1 px lines `#2a8040`; buildings as filled polygons
  (`#1f5a2a`, named buildings `#48e06a`); the player as a filled triangle
  (6 px) at the centre pointing up when `headingUp` (else rotated by yaw);
  the letter `N` (`#8aff9e`, 10 px monospace) placed 8 px inside the edge in
  the rotated north direction. `update` must not allocate typed arrays or
  re-bucket; plain per-frame path math is fine.
- `src/hud/minimap.css` (imported by `minimap.ts`): `.minimap { display:block; margin-top: 8px; border: 1px solid #1f5a2a; image-rendering: pixelated; }`.
- No top-level DOM access (node imports the module for tests).
- Write `docs/minimap.md` (projection formula, colours, cell grid, how to
  wire it — it will live inside `#hud` under the rows).
