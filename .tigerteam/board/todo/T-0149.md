## Goal
Replace the `retrocgi` stub with the real style: the glider display from
*Escape from New York* (1981) — chunky glowing phosphor-green outlines of
the city on a black tube, one bright shoreline, and nothing else. The
formula is locked in `docs/architecture.md` §4.11, subsection
"`retrocgi` (wave 19 …)" — read it first; it is the contract. The stub
already ships and is registered (`STYLE_ORDER`, `styles/index.ts`, `R`
cycles to it, `?render=retrocgi` selects it).

## Context
- Rewrite `src/render/styles/retrocgi.ts` wholesale. Keep the exported
  shape: `export const STYLES: readonly RenderStyle[]` with ONE entry,
  `id: 'retrocgi'`, `label: 'RETRO CGI'`, `cellW: 2`, `cellH: 2`,
  `subX: 1`, `subY: 1`, `needsDepth: true`, `groundGrid: false`,
  `targetCap: { w: 960, h: 540 }`, `makeUniforms: () => ({})`.
- Pattern to copy: `src/render/styles/edges.ts` (the five `linearDepth`
  samples one target texel apart, `stepUv = 1.0 / sceneSize`, and the sky /
  inverse-depth second-difference test). `import { isEdge } from './edges'`
  for the pure mirror — do NOT edit `edges.ts` and do not copy `isEdge`.
  In GLSL put the five-sample edge test in a function `bool edgeAt(vec2 uv)`
  and call it five times (centre + the four cells two texels away).
- GLSL ES 1.0: no `!=` on `bvec`, no dynamic loops needed — unroll the four
  neighbours. Read `src/render/style.ts` for the prelude; never redeclare
  its uniforms (`tScene`, `tDepth`, `sceneSize`, `grid`, `time`,
  `cameraFar`, `exposure`, …) and never name a local `bright` or `shaped`.
  Scene colour = `texture2D(tScene, uv).rgb * exposure`.
- The shoreline term is what makes this style more than `edges`: water and
  land are coplanar, so only the colour test can see the coast. Skip it
  when the centre sample is sky.
- Pure exports, each with a one-line JSDoc, mirroring the shader term for
  term (names and argument orders are locked by §4.11):
  `RETRO_LINE`, `RETRO_BG`, `HALO_GAIN`, `FADE_NEAR`, `FADE_FAR`,
  `FADE_MIN`, `FLICKER`,
  `isWaterColour(rgb: readonly [number, number, number]): boolean`,
  `retroEdge(depths: readonly number[] /* C,L,R,U,D */, colours: readonly (readonly [number, number, number])[] /* C,L,R,U,D */, far: number): boolean`,
  `retroFade(dNear: number): number`,
  `retroIntensity(e0: boolean, haloCount: number /* 0–4 */, dNear: number, flick: number): number`,
  `retroColour(i: number): [number, number, number]`.
- New unit file `tests/styles/retrocgi.test.ts` (vitest, node, no WebGL —
  copy the shape of `tests/styles/edges.test.ts`). Cases, by name:
  1. `isWaterColour` of `WATER_HEX` 0x163a6b as floats `(22, 58, 107)/255`,
     and of the same colour × 0.3 (night) and × 1.7 (exposed) → true;
  2. `isWaterColour` of grey `[0.5, 0.5, 0.5]`, green `[0.1, 0.6, 0.2]`,
     black `[0, 0, 0]`, and pale blue-grey `[0.5, 0.55, 0.6]` → false;
  3. `retroEdge`: flat plane (five equal depths, five equal greys) → false;
  4. `retroEdge`: depth step (C 50, R 80, others 50) → true;
  5. `retroEdge`: equal depths, centre land / left neighbour water → true
     (shoreline);
  6. `retroEdge`: all five samples sky (`depth = far`) with one "water"
     coloured sample → false (shoreline skipped in sky);
  7. `retroEdge`: centre sky, one neighbour at 100 m → true (skyline);
  8. `retroFade`: ≤ 150 → 1, ≥ 900 → 0.35, 525 → 0.675 (`toBeCloseTo`),
     monotone non-increasing over 0…1200 in steps of 50;
  9. `retroIntensity(true, 0, 100, 1)` → 1; `(false, 4, 100, 1)` → 0.30;
     `(false, 2, 100, 1)` → 0.15; `(false, 0, 100, 1)` → 0;
     `(true, 4, 100, 1)` → 1 (halo never adds to a line cell);
  10. `retroColour(0)` → `RETRO_BG`; `retroColour(1)` → channels
      `[0.30, 1.0, 0.47]` clamped to ≤ 1; every channel of `retroColour(i)`
      is within [0, 1] for i in 0…1.5.
- New doc `docs/styles/retrocgi.md`: copy the shape of
  `docs/styles/edges.md` — cell/sub/depth/flags line, "Algorithm (per
  cell)" numbered steps, the constants table, shader notes (25 + 25 taps,
  shoreline term, why `isEdge` is imported), the pure exports list.
- **Never read or open any `.png`** (your model may reject image input and
