## Goal
The virtual joystick works but is invisible until touched — players don't
find it. Show a faint idle ring anchored bottom-left; touching anywhere in
the left half still starts the joystick at the touch point (unchanged).

## Context
- `TouchControls` (`src/player/touch.ts`, T-0025) creates `.touch-joystick-ring`
  / `.touch-joystick-knob`, shown only while a joystick pointer is active.
- Changes:
  1. New CSS state `.touch-joystick-ring.idle`: `display: block; opacity: 0.28;`
     positioned at `left: 18vw; bottom: 90px; top: auto; transform: translate(-50%, 50%)`
     (the active state keeps today's behaviour and full opacity; knob hidden
     while idle).
  2. `TouchControls`: on construction add the `idle` class; on joystick
     `pointerdown` swap `idle` → active placement (existing code); on
     `pointerup`/`pointercancel` return to the idle state instead of hiding.
  3. Keep `hideStick`/`showStick` internals free to change, but the public
     API (`readInput`, `dispose`) and all existing behaviour stay identical.
- `docs/controls.md`: update the Touch section (idle hint, unchanged input model).
