## Goal
The retro-terminal finish: a pointer-transparent overlay on top of the canvas
with faint scanlines, a vignette, and a soft green border glow like the
reference look. Module only; wiring (and the `?crt=0` switch) is a later ticket.

## Context
- Export (exact): `export function mountCrt(parent: HTMLElement): HTMLElement`
  — creates `<div class="crt" aria-hidden="true">` with two children
  `<div class="crt-scan">` and `<div class="crt-glow">`, appends it to
  `parent`, returns the outer div. No top-level DOM access; import
  `./crt.css` from `crt.ts`.
- `src/render/crt.css`:
  - `.crt { position: fixed; inset: 0; pointer-events: none; z-index: 5; }`
  - `.crt-scan { position: absolute; inset: 0; background: repeating-linear-gradient(to bottom, rgba(0,0,0,0) 0px, rgba(0,0,0,0) 2px, rgba(0,0,0,0.22) 3px); mix-blend-mode: multiply; }`
  - `.crt-glow { position: absolute; inset: 0; box-shadow: inset 0 0 140px rgba(0,0,0,0.75), inset 0 0 24px rgba(72,224,106,0.10); }`
  - `@media (prefers-reduced-motion: reduce)` is not needed (nothing animates).
- Append a "CRT overlay" section to `docs/render.md` (what each layer does,
  how to disable it once wired).
