## Goal
Generate and commit `public/data/kyiv.json` — central Kyiv with real SRTM
terrain and English names — via the existing pipeline extended with the
flags in `docs/data-format.md` (§Datasets, §Names and --lang, §Terrain,
§Fetch script CLI). London's `city.json` is NOT regenerated.

## Context
- `scripts/dem.mjs` (T-0039) provides `fetchDemTiles` and `buildTerrain`;
  `src/data/validate.ts` (T-0041) already accepts `terrain`/`waterLevels`.
- Converter: `convertOverpass(json, opts)` gains `opts.lang?: string`
  (prefer `name:<lang>`, else `name`, for buildings, roads, places),
  `opts.dem?: { elevationAt(lat, lon): number }` and `opts.step?: number`;
  when `dem` is given, call `buildTerrain({ bbox, origin, dem, step, waterRings: water })`
  after water clipping and emit `terrain` + `waterLevels` (omit `waterLevels`
  when there is no water). Update `scripts/osm-convert.d.ts`.
- Roads: `footway` ways whose `bridge` tag is present and not `no` are
  emitted as `cls: 'pedestrian'` with `bridge: true` (Kyiv's Park and
  Klitschko pedestrian bridges); plain footways stay dropped.
- CLI: `--lang en`, `--dem 1`, `--step 20`; with `--dem 1` fetch tiles
  (`.cache/dem/`) before converting; the Overpass timeout may go to 300 s
  for the larger box. Summary line format per data-format.md.
- Command to run (also wired as `npm run fetch-data:kyiv` — package.json is
  already updated by the PM, do not edit it):
  `node scripts/fetch-osm.mjs --bbox 30.495,50.422,30.585,50.470 --origin 30.5234,50.4501 --lang en --dem 1 --out public/data/kyiv.json`
- Fixture: add `name:en` to one building and one road, and one
  `highway=footway` + `bridge=yes` way to `tests/fixtures/overpass-small.json`.
- `tests/data.test.ts`: mirror the existing committed-dataset test for
  `public/data/kyiv.json` (validates, has `terrain`, `waterLevels.length === water.length`, `heights` within ±150 of 0, file < 10 MB).
- Docs: `docs/fetch-osm.md` — flags, the Kyiv command, summary line, the
  footway-bridge rule.
