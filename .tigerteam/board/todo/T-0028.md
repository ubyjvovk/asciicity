## Goal
Start the game with Big Ben straight ahead: the default spawn (no `?at=`)
becomes a point on Westminster Bridge looking west at the Elizabeth Tower,
and a few Westminster presets join the list.

## Context
- `src/data/spawn.ts` (T-0022): `SPAWN_PRESETS` is `Record<string, SpawnPreset>`
  with `{ lon, lat, bearingDeg, label }`; `resolveSpawn` falls back to the
  `bank` preset when `param` is null/unknown.
- Add presets (lon, lat, bearingDeg, label):
  `bigben` (−0.12235, 51.50085, 268, "Westminster Bridge, facing Big Ben"),
  `parliament` (−0.12655, 51.50060, 90, "Parliament Square, facing the Palace of Westminster"),
  `trafalgar` (−0.12800, 51.50790, 180, "Trafalgar Square, facing Whitehall"),
  `embankment` (−0.12200, 51.50740, 120, "Victoria Embankment, facing the London Eye").
- Change the default: `resolveSpawn` uses `bigben` when `param` is null,
  empty, or unknown (`bank` stays available as `?at=bank`). The
  `synthetic=1` path in `main.ts` is unaffected (it never calls `resolveSpawn`).
- Adjust existing tests accordingly (the "defaults to the bank preset"
  case becomes "defaults to bigben": expected point = `project(-0.12235, 51.50085, ORIGIN)`
  and yaw = `normalizeAngle(268°)`), add one case per new preset key, keep
  all coordinate/blocked-walk cases.
- Docs: `docs/integration.md` preset table + default; README "How to play".
- Visual check (throwaway Playwright, GPU flags if available:
  `--use-angle=gl-egl --ignore-gpu-blocklist`, else SwiftShader with `?cell=3x6`):
  load `/` with no params and confirm the HUD ZONE reads a Westminster
  street/bridge and the LANDMARK row or the view shows the tower; describe it.
