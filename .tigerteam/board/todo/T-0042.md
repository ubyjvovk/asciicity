## Goal
The runtime half of terrain: `docs/architecture.md` §4.9 — a triangle
interpolating sampler that is exactly the surface the heightfield mesh
draws, the mesh itself with slope shading, straight bridge decks between
abutments, and `makeGroundAt` (the walkable `HeightFn`). Everything except
`makeTerrainObject` is pure and unit-tested in node.

## Context
- Contract: `docs/architecture.md` §4.9 — implement every signature exactly
  (`Terrain`, `terrainHeightAt`, `buildTerrainGeometry`, `makeTerrainObject`,
  `bridgeProfile`, `BridgeDecks`, `makeGroundAt`). Types: `TerrainData`,
  `HeightFn`, `FLAT_HEIGHT`, `Road`, `Vec2` from `src/data/types.ts`;
  `ROAD_WIDTH` from `src/world/roads.ts`; `makeGridTexture` from
  `src/world/ground.ts` (call it only inside `makeTerrainObject` so node can
  import the module). `distToSegment` from `src/world/collision.ts`.
- `buildTerrainGeometry` returns an **indexed** `THREE.BufferGeometry`
  (`setIndex`, `position`, `uv`, `color` attributes, `computeVertexNormals`,
  `computeBoundingSphere`) — not `MeshData`. `THREE.BufferGeometry` works in
  node (§8).
- `BridgeDecks` bucketing mirrors the corridor bucketing in
  `CollisionGrid` (`src/world/collision.ts`, `corridorCells`): same 25 m
  cells, same `ROAD_WIDTH[cls] / 2 + 1` half-width.
- Docs: new `docs/terrain.md` — the sampling rule with a worked example, the
  geometry layout (index order, diagonal, shade formula), the bridge rule,
  and how `main.ts` is expected to compose them (quote §5).

## Acceptance criteria
- [ ] `bash .tigerteam/scripts/run-tests.sh tests/terrain.test.ts` exits 0
- [ ] Tests cover, by name: `terrainHeightAt` returns node heights exactly at nodes; the diagonal midpoint of a cell equals `(h00 + h11) / 2`; a point with `fu > fv` uses `h10` and one with `fu < fv` uses `h01` (asymmetric 2×2 grid); points outside the grid clamp to the edge value on all four sides; a grid filled from the plane `h = 2x + 3z` reproduces the plane at 20 random points to 1e-9; `Terrain.min`/`max`; `buildTerrainGeometry` has `cols·rows` vertices and `6·(cols−1)·(rows−1)` indices, every triangle's `cross(b−a, c−a).y > 0`, a flat grid gives normals `(0,1,0)` and every colour component `1.0`, a plane tilted away from `L` gives colours `< 1`, vertex `(c, r)` has `uv = (x/40, z/40)`, and `terrainHeightAt` at the centroid of every triangle of a random 4×3 grid equals the average of that triangle's three vertex heights (sampler ≡ mesh); `bridgeProfile` on a 2-point polyline → `[ya, yb]`, a 3-point polyline over a dip → middle = lerp, over a bump → middle = terrain; `BridgeDecks.deckAt` mid-span returns the lerp, a point beyond the half-width returns `undefined`, non-bridge roads are ignored, two overlapping decks return the max; `makeGroundAt(undefined, undefined)(x, z) === 0`, terrain only, deck above terrain wins, terrain above deck wins
