## Goal
User: "there's no way to press the gear icon on desktop" — under pointer
lock nothing is clickable and after Esc the menu overlay covers it, so it
is redundant there. Per the revised `docs/architecture.md` §4.12: show
`#gear` only on touch devices; on desktop the HUD help line ends with
`· ESC MENU`.

## Context
- Detection: the same expression `main.ts` already uses to create
  `TouchControls`; set `gear.hidden = !touch` (and keep the CSS).
- Help line: desktop default becomes
  `'WASD MOVE · MOUSE LOOK · SHIFT RUN · F FLY · R STYLE · ESC MENU'`; the
  touch variant unchanged.
- e2e: the existing `smoke: panels (touch …)` keeps its gear tap; add to the
  desktop smoke: `#gear` is hidden and the HUD contains `ESC MENU`.
- Docs: `docs/integration.md`, `docs/hud.md`.
