## Goal
User review of v3: the sky reads as "a big wire dome" and "many surfaces
shimmer when walking". Both are v3 formula defects, fixed by the five
locked changes in `docs/architecture.md` §4.11, subsection "`scribble` v4
(T-0138)" — read it first; it is the contract: (1) per-pixel depth `dPix`
feeds the wall position too; (2) wobble and lifts in world metres with
screen-size fades, never `ma` in a phase; (3) soft layer switching;
(4) wider anti-aliasing; (5) short hair strokes on the sky dome replacing
the tangle.

## Context
- Edit `src/render/styles/scribble.ts` in place; keep the exported `STYLES`
  shape and every v3 export the spec does not delete. `tangleInk` is
  deleted; new pure exports: `wobble(along, ph, mu, ma)`,
  `lifted(key, along, ma): boolean`, `hairInk(ps: [x, y], density)`;
  `skyDensity` gets the new endpoints (0.75 / 0.45).
- The hair loop is 3 × 3 cells × 3 strokes = 27 segment evaluations per
  sky pixel — constant-bound loops, fine in GLSL ES 1.0. Sky pixels are
  the only ones that pay for it.
- Unit tests (`tests/styles/scribble.test.ts`): keep the v3 cases that
  still apply; delete the `tangleInk` cases; update `skyDensity`
  expectations; add, by name:
  1. `wobble` stability — for 50 random `(along, ph, mu)` samples, the
     value at `ma = 0.05` equals the value at `ma = 0.1` (toBeCloseTo, 9)
     (all three octaves fully visible for both);
  2. `wobble` fades — at `ma = 5` (every period < 3 cells) the value is
     0 for any input; at `ma = 1.2` only the 14 m octave contributes
     (value equals `mu · 0.3 · sin(2π·along/14 + 3ph)`, toBeCloseTo, 6);
  3. `lifted` — never true at `ma = 10` (nothing visible); over a 1000 m
     line at `ma = 0.05` the lifted fraction is between 0.05 and 0.25;
  4. `hairInk([x, y], 0)` → 0 on a 64 × 64 grid at 1-cell steps; every
     value at density 1 lies in `[0, 1]`; the grid mean is strictly
     increasing across densities `[0, 0.45, 0.75, 1]`, and at density 0.75
     the mean is between 0.05 and 0.30;
  5. hair points up — for 200 random `ps` with `|ps| > 20`, the stroke
     direction `dir` computed for that point's own cell and stroke 0 has
     `dot(dir, normalize(−ps)) > 0.8` (export a small helper
     `hairDir(c: [cx, cy], s): [x, y]` for this).
- `docs/styles/scribble.md`: rewrite the wobble/lift step, the sky step
  (hair), the pure-exports list.
- **Never read, open or view any `.png`**; `ls -la` only. The PM does the
  visual review (two frames one step apart, and a sky pan).
