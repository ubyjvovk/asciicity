## Goal
The cyberpunk style currently paints every building as a wall of glowing
windows on a flat surface. Replace the facade materials with the look of the
reference (threejs-conference `public/preview.jpg`): dark weathered
concrete/metal facades with floor bands, panel seams and rain/grime streaks,
**sparse and dim** lit windows (8–14 %), a quarter of buildings dark, dark
reflective glass, and a street-level shopfront band of shutters and lit shop
glass. The full numeric contract is docs/architecture.md §4.11
"`cyberpunk` v2 (wave 20b)" → "Facades" and "Plumbing" — read both first.

## Context
- `src/render/punk/facade.ts` exists (PM split) and currently holds the
  wave-20 prototype look; keep its exported API exactly:
  `makeFacadeMaterials(windowTex: THREE.Texture | null, u: WetUniforms): FacadeMaterials`
  returning `{ walls, roof }` (`MeshStandardNodeMaterial`s). `WetDressing`
  (`wet.ts`, PM-owned) calls it and assigns `[walls, roof]` to every mesh
  tagged `userData.surface === 'buildings'`.
- Wall geometry facts (`src/world/buildings.ts`): UV u = perimeter metres /
  24, v = (y − wall base) / 24; so `u·8`, `v·8` index 3 m × 3 m window
  cells, and the atlas window occupies px x∈[2,6), y∈[1,6) of each 8×8 cell
  (`src/world/textures.ts`). Vertex colour is per building (use it as the seed
  and base tint). `windowTex === null` for stone cities (Minas Tirith): then
  no windows, just the material.
- Noise/hash: ONLY `src/render/punk/noise.ts` (`hash2Node`, `vnoiseNode`,
  `fbm2Node` in TSL; `hash2`, `vnoise`, `fbm2` JS mirrors). Ripples on the
  roof: `rippleNormal(u, 4.8, strength)` from `ripples.ts`.
- Put every number / decision that the shader uses in the pure
  `src/render/punk/facademath.ts` (NO `three/webgpu` import there) and
  import the constants into facade.ts, so the unit tests and the shader can't
  drift. Required pure exports (§4.11): `buildingSeed(r, g, b)`,
  `windowLight(cellU, cellV, seed) → { lit, intensity, tint: 0|1|2|3, blinds }`,
  `isDarkBuilding(seed)`, `shopfrontKind(segment, seed) → 'shutter' | 'shop'`,
  the tint palette and shares, band/seam sizes. The shader must implement the
  same decisions with `hash2Node` on the same inputs.
- TSL tips: `bumpMap(heightNode, scale)` from 'three/tsl' perturbs normals;
  `select(cond, a, b)`; `positionLocal`/`uv()`/`vertexColor()`. Emissive goes
  in `emissiveNode` (it feeds bloom via the emissive MRT). Glass reflects
  via low roughness + metalness 0.6 (the pipeline's SSR reads metalness).
- Look reference in words: in the reference, a facade is ~90 % dark
  material; lit windows are small warm points, a few cool/neon; the ground
  floor is the brightest band. The PM judges this on the GPU and WILL rework
  a facade that still reads as a window grid.
- **Never open or read any `.png`/`.jpg`** (your model may reject images and
  the attempt dies); verify via tests and `__asciicity.punk`.

## Questions

**`check.sh` e2e cannot go green without a 2-line change in PM-owned `src/main.ts`.**

- **Symptom:** `e2e/groundgrid.spec.ts` “crayon hides the terrain grid, ascii restores it (Minas Tirith)” — ascii grid-green = 0. Boots crayon, `R` through pastel → watercolor → **cyberpunk** → ascii, looks straight down at the citadel terrain.
- **Cause:** `applyStyleChange` (`src/main.ts` ~1338) does `applyGroundGrid()` then `syncEngine()`. `setGroundGrid` writes `material.map` on **whatever is currently on the mesh**. If `WetDressing` node materials are still applied, the grid texture lands on the node material and is discarded by `wet.restore()`, which returns the original MeshBasic/Lambert still holding the crayon **plain** map.
- **Why this ticket trips it:** the v2 wall graph is heavier than the wave-20 prototype. On a warm Vite cache, `createPunkView` + first compile finish during the test’s 2-rAF pause on cyberpunk, so `wet.apply` has run before `R` to ascii. Prototype often missed that window (isolated original facade: ascii green **0.0320**). This is a pre-existing race, not a wrong grid in the facade shader (facades do not touch terrain).
- **Verified fix (applied, minas passed at 0.0320 after a 26 s cyberpunk compile, then reverted — not committed):**

```ts
// applyStyleChange: restore WebGL materials first, then swap the grid map
syncEngine();
applyGroundGrid();
```

Going *to* cyberpunk: `setActive` saves the current maps, then `applyGroundGrid(false)` hits the node material (harmless). Going *to* ascii: restore originals, then `applyGroundGrid(true)` writes the grid onto the restored material.

- **Recommendation:** PM lands that swap (or equivalent: `applyGroundGrid` after `wet.restore()`). Requeue this ticket; no facade rework needed. I can cherry-pick nothing — the commit on `tigerteam/T-0152` is the v2 materials.
