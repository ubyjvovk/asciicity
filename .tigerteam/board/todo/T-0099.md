## Goal
Prove streaming holds up under movement: tiles unload and dispose, the
loaded set stays bounded, hysteresis prevents thrash, and collision under
the player never gaps at boundaries. Tests only — if these tests expose a
product bug, file `## Questions` with the failing evidence instead of
patching `src/` (out of scope here).

## Context
- **Read first**: architecture.md §4.19; `docs/streaming.md`;
  `e2e/tiles.spec.ts` as landed by T-0095/96/98. Debug surface:
  `__asciicity.tiles = { loaded, pending, version, disposed }`,
  `?tileradius=<m>`. Movement in e2e: fly mode (`F`, look + `W`) covers
  ground fastest; `?tileradius=400`-ish makes transitions cheap.
- The wave-10 flake lessons apply: poll state with tolerant timeouts, pin
  determinism where possible, and remember SwiftShader is slow — no
  wall-clock assertions tighter than seconds.
