## Goal
Hand-picked preset coordinates land in side streets with the landmark out of
frame (`?at=gherkin` today). Resolve landmark presets from the dataset
instead: find the named building, pick a road point about 70 m from its
centroid, and face it.

## Context
- `src/data/spawn.ts` (T-0022): keep `parseAt`, `resolveSpawn`'s signature
  compatibility for the coordinate form, and the +x walk rule. Change
  `SpawnPreset` to `{ building: string; label: string }` where `building` is
  a case-insensitive substring matched against `Building.name`:
  `bank`, `bigben`, `parliament`, `trafalgar`, `embankment` → keep as fixed coordinate presets (T-0028); the default stays `bigben` since
  "Bank" is a place, not a building; `stpauls` → "St Paul's Cathedral";
  `gherkin` → "30 St Mary Axe"; `monument` → "Monument"; `tower` → "Tower of London"
  (may be absent from the bbox — fall back to `bank` when no building
  matches, logging nothing); `barbican` → "Barbican"; `liverpoolst` →
  "Liverpool Street"; `leadenhall` → "Leadenhall Market"; `walkietalkie` →
  "20 Fenchurch Street"; `lloyds` → "Lloyd's". Allow `SpawnPreset` to carry
  either `{ building }` or `{ lon, lat, bearingDeg }` (a discriminated union).
- New pure export `landmarkSpawn(name: string, city: Pick<CityData, 'buildings' | 'roads'>, targetDist = 70): SpawnPoint | null`:
  1. building = first `buildings[]` whose `name` contains `name`
     (case-insensitive); centroid `c` = mean of its `poly`; null if none.
  2. candidate points = every `roads[].pts` vertex (all classes) within
     `[targetDist − 40, targetDist + 60]` metres of `c`; if none, all road
     vertices within 200 m; if still none, return null.
  3. pick the candidate with the smallest `|dist − targetDist|`.
  4. yaw = `atan2(c.x − p.x, −(c.z − p.z))` (faces the centroid; consistent
     with forward = `(sin yaw, −cos yaw)`).
- `resolveSpawn(param, origin, blocked, city?)` gains an optional 4th arg;
  when a preset has `building` and `city` is given, use `landmarkSpawn`,
  falling back to the `bigben` coordinate preset when it returns null.
  `main.ts` passes `city`.
- Update `docs/integration.md` preset table (names → matched building) and
  README.
