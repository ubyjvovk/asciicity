## Goal
The user cannot find Kyiv's landmarks because OSM gives them stub heights
(Saint Sophia 3 m, Lavra bell tower 8 m, the Arch 3 m) and has no Motherland
Monument. Implement `docs/architecture.md` §4.13: a curated fix table
applied at load, an extra synthetic Motherland Monument, presets that
resolve to real buildings, exact-name matching and height-scaled spawn
distance, and `presetsFor(city)` for the coming fast-travel menu.

## Context
- `src/world/landmarks.ts` (new) per §4.13 — `LANDMARK_FIXES`,
  `EXTRA_BUILDINGS`, `applyLandmarks(city, cityId)` (pure; use `project`
  from `src/geo.ts` for the extra footprint: a square of side `size` centred
  on the point, ids from −1000 downward, `name` set, `h` set).
- `src/world/palette.ts`: add `registerLandmarkColors(map: Record<string, number>)`
  and make `landmarkColor`/`colorFor` consult the registered map first;
  existing London table and tests unchanged.
- `src/data/spawn.ts`: `city` field on every preset (London ones `'london'`);
  `presetsFor(cityId)`; `landmarkSpawn` exact-match-first + `targetDist`
  default `clamp(70 + 1.2·h, 70, 220)` (explicit `targetDist` argument still
  wins); the Kyiv preset changes listed in §4.13 (`rada`, `volodymyr`,
  `arch`, `olimpiyskiy`, `nicholas` added; `mariinsky` removed; the named
  ones switched to `{ building, city, label }` with their previous
  coordinates kept as the fallback `{ lon, lat, bearingDeg }`).
- `src/main.ts`: `city = applyLandmarks(city, cityInfo?.id ?? 'synthetic')`
  right after `chooseCity` (one line; synthetic/unknown ids are no-ops).
- Tests: `tests/landmarks.test.ts` — applying to `kyiv.json` sets Saint
  Sophia Cathedral to 29 and Great Lavra Belltower to 96, appends exactly
  one extra building named `Motherland Monument` with a 4-point square of
  side 20 within 1 m of the projected point and id ≤ −1000, leaves the
  building count + 1 and every other height unchanged, is idempotent
  (applying twice adds no second monument), and London/synthetic are
  returned unchanged (deep-equal); `colorFor` of the fixed Sophia is gold.
  `tests/spawn.test.ts` — `presetsFor('kyiv')` has no London keys and vice
  versa, every Kyiv building preset resolves via `landmarkSpawn` against
  `applyLandmarks(kyiv.json)` (list them), exact match beats includes
  (fixture with `Sophia Hotel` listed before `Saint Sophia Cathedral`),
  distance scaling: a 96 m building yields a spawn 150–220 m away, a 10 m
  one 70–130 m. `tests/buildings.test.ts`: `colorFor` after
  `registerLandmarkColors({ X: 0x123456 })` returns it for `X`.
- Docs: `docs/world.md` (landmark fixes section: the table, how to add a
  city), `docs/integration.md` (updated Kyiv presets table).
