## Goal
The user: "add a small 'loading' indicator somewhere like the bottom left
corner, something in character". After the first load (the full-screen
overlay) the game keeps loading things in the background with no feedback:
streamed city tiles, the lazily imported cyberpunk engine, cyberpunk layer
cells (detail / props / neon), and the 22 MB of car models. Show a small
retro-terminal status line while any of that is in flight.

## Design (LOCKED — flag, don't redesign)
**Placement.** A new `<div id="busy">` fixed at `left: 0; bottom: 0;
height: 20px`, i.e. the LEFT END of the existing 20 px `#credits` bar
(src/style.css "Credits footer"). `z-index: 6` (credits is 5),
`background: #000`, `padding: 0 8px`, `pointer-events: none`, monospace
11 px, `line-height: 20px`, `white-space: nowrap`, full opacity (the credits
text is 0.55 — the indicator must read brighter). It must NOT move `#toast`
or `#gear`. Below 600 px viewport width show only the spinner + bar (hide the
label span) so it cannot cover the centred credits text on phones.

**Look — in character.** One line, e.g.

```
⠹ SYNC ▱▰▰▰▱▱▱▱ SECTORS 3 · CARS
```

- Spinner: braille frames `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏`, one frame per 80 ms.
- Bar: 8 cells, indeterminate — a 3-cell `▰` block ping-pongs across `▱`
  cells, one step per 120 ms (we do not know totals; do not fake a percent).
- Verb: `SYNC`, except `BOOT` while the cyberpunk engine itself is loading.
- Label: the active items, in this order, joined by ` · `:
  `SECTORS n` (tile manager pending > 0), `NEON GRID` (cyberpunk engine
  status `'loading'`), `CELLS n` (sum of every cyberpunk stats key ending in
  `.pending`), `CARS` (`vehicles.on === 1 && vehicles.ready !== 1`, or
  `vehicles.loading > 0`).
- Colour: `var(--hud-green)` normally. While the active render style is
  `cyberpunk`, neon: text `#ff3ad8`, bar cells `#3ef2ff`, with a
  `text-shadow: 0 0 6px currentColor` glow (a CSS class on `#busy`).

**Behaviour.**
- Hidden while the first-load overlay is up (`loading.phase !== 'ready'`),
  when the HUD setting is off (`settings.hud === false` — `?hud=0`, so PM
  screenshot frames stay clean), and when idle.
- Hysteresis (no flicker on one quick tile): appear only after the busy state
  has been continuously non-empty for ≥ 300 ms; after it goes idle, keep
  the last line for 600 ms and fade out (opacity transition 0.25 s).
- Polling: read the sources at most every 250 ms (`punk.stats()` builds an
  object — never call it every frame). Spinner/bar animate from the frame
  time; update `textContent` only when the string changes. No per-frame
  allocation in the hot path beyond that string.

**Code split (AGENTS.md: pure vs DOM).**
- `src/hud/busy.ts` (pure, no DOM, no three):
  - `interface BusyInputs { tilesPending: number; engineLoading: boolean; cellsPending: number; carsLoading: boolean }`
  - `busyInputsFromStats(tilesPending: number, engineStatus: string, stats: Readonly<Record<string, number>>): BusyInputs`
  - `busyLabel(i: BusyInputs): string` — `''` when idle, else the label above.
  - `busyLine(i: BusyInputs, tMs: number, narrow: boolean): string` — the full line
    (spinner + verb + bar [+ label unless `narrow`]), `''` when idle.
  - `class BusyGate { constructor(showAfterMs = 300, holdMs = 600); step(busy: boolean, tMs: number): boolean }` — the hysteresis.
  - Exported constants `SPINNER_FRAMES`, `SPINNER_MS = 80`, `BAR_CELLS = 8`, `BAR_MS = 120`, `POLL_MS = 250`.
- `src/hud/busyview.ts` (DOM, thin): `class BusyView { constructor(parent: HTMLElement); update(inputs: BusyInputs | null, tMs: number, neon: boolean, visible: boolean): void; dispose(): void }`.
  Keeps a label `<span>` for the narrow-width CSS rule.
- `src/main.ts` (PM-owned — this ticket may add ONLY: the import, one
  `BusyView` mount next to `mountCredits`, and a ~10-line poll+update block
  in the frame loop). Sources: `tileMgr?.pending() ?? 0`,
  `punkDebug.status`, `punkDebug.stats()`, `settings.hud`,
  `loading.phase`, the active style id (`post.style.id === 'cyberpunk'`).
- CSS in `src/style.css`, a new commented `#busy` block after `#toast`.
