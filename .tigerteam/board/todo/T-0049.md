## Goal
Press `F` to take off: fly where you look (mouse pitch steers), `Space`/`C`
for straight up/down, `Shift` for 90 m/s, no collision while airborne,
ground-clamped, 1 500 m ceiling; fog thins with altitude so the whole city
is visible from above; `F` again lands (constant-speed fall). Full contract:
`docs/architecture.md` §4.7 (updated 2026-08-26) and its "Frame loop
consequences" paragraph — implement every signature and rule exactly.

## Context
- `src/player/controls.ts`: extend `PlayerState` (`y`, `fly`), `InputState`
  (`up`, `flyToggles`), constants (`EYE_HEIGHT`, `FLY_SPEED`,
  `FLY_SPRINT_SPEED`, `FALL_SPEED`, `MAX_ALTITUDE`), `stepPlayer(..., groundAt = FLAT_HEIGHT)`
  per §4.7; `Controls`: `Space`/`KeyC` held keys → `up` (extend
  `axesFromHeld`), `KeyF` keydown without repeat → `flyToggles++`,
  `Space` keydown `preventDefault()`. `HeightFn`/`FLAT_HEIGHT` come from
  `src/data/types.ts`.
- `src/player/touch.ts` is out of scope: `mergeInput` must keep compiling —
  give `TouchControls.readInput()`'s result `up: 0, flyToggles: 0` **from
  main.ts's merge side only if needed**; if `mergeInput` needs the two new
  fields, add them there minimally (`up: clampAxis(a.up + b.up)`,
  `flyToggles: a.flyToggles + b.flyToggles`) and mention it in the report
  (touch.ts is then in scope for that one edit).
- `src/main.ts`: import `EYE_HEIGHT` from controls (delete the local
  const); `state.y = groundAt(spawn) + EYE_HEIGHT`, `state.fly = opts.fly`
  (`?fly=1`); pass `groundAt` to `stepPlayer`; `camera.position.y = state.y`,
  sky likewise; per frame `agl = state.y − EYE_HEIGHT − groundAt(x, z)` and
  `fog.density = 0.0018 / (1 + agl / 150)` (guard `instanceof THREE.FogExp2`);
  on a fly toggle `camera.far = fly ? 6000 : 2000; camera.updateProjectionMatrix()`;
  `window.__asciicity.fly`; `api.y = state.y`; HUD `mode = fly ? 'FLY' : undefined`,
  `alt` per §4.7 (`formatAlt(m, unit = 'ASL')` → `"<round> M <unit>"`);
  `Hud` help default `'WASD MOVE · MOUSE LOOK · SHIFT RUN · F FLY'` (keep the
  touch variant as is).
- `src/hud/hud.ts`: `HudValues.mode?: string`; `MODE` row between LANDMARK
  and FPS only when defined (so 6–8 rows).
- e2e: add `smoke: fly` — `/?synthetic=1&fly=1`, wait ready, click, hold
  `Space` 500 ms, assert `__asciicity.y` rose by ≥ 5 m and `__asciicity.fly === true`,
  HUD contains `MODE` and `FLY`; keep the two existing tests.
- Docs: `docs/controls.md` (fly section: keys, speeds, noclip, fall),
  `docs/integration.md` (`?fly=1`, fog/far rules, `__asciicity.fly`),
  `docs/hud.md` (MODE row, ALT AGL).
