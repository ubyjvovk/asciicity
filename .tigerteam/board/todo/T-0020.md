## Goal
Ship a favicon so the tab shows the game's mark and the console stops logging
a 404 for `/favicon.ico`.

## Context
- `index.html` (T-0010/T-0017) is the only page. Vite serves `public/` at the
  site root and `import.meta.env.BASE_URL` / the `base` config handle the
  GitHub Pages prefix — use a root-relative link that Vite rewrites:
  `<link rel="icon" type="image/svg+xml" href="/favicon.svg" />` (Vite
  rewrites `/favicon.svg` with `base` at build time because it is a
  `<link href>` in `index.html`).
- `public/favicon.svg`: 64×64 viewBox, black square background (`#000`),
  a 1 px `#1f5a2a` inner border, and a bold monospace `@` glyph in `#48e06a`
  centred (use `<text>` with `font-family="DejaVu Sans Mono, Courier New, monospace"`,
  `font-size="44"`, `text-anchor="middle"`, `dominant-baseline="central"`).
  Keep it under 1 KB; no external references.
- Also add `<meta name="description" content="Walk around the City of London rendered as ASCII.">`
  and `<meta name="theme-color" content="#000000">` to `<head>`.
- Note the favicon in `docs/integration.md` (assets section).
