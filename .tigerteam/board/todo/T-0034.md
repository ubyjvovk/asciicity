## Goal
Put the Sun and Moon where they really are over London (no relighting — just
visible discs on the black sky), plus ~300 faint stars when the sun is down.
Time defaults to the real clock; `?time=` pins it for testing.

## Context
- Coordinates: architecture.md §3. Azimuth is degrees clockwise from north;
  a direction from (azimuthDeg A, altitudeDeg h) is
  `dir = (sin A·cos h, sin h, −cos A·cos h)` (degrees → radians first).
- New pure module `src/world/sky.ts`:
  1. `export function sunPosition(date: Date, latDeg: number, lonDeg: number): { azimuthDeg: number; altitudeDeg: number }`
     — NOAA low-precision, implement exactly:
     `jd = date.getTime()/86400000 + 2440587.5`; `n = jd − 2451545.0`;
     `L = (280.460 + 0.9856474·n) mod 360`; `g = (357.528 + 0.9856003·n) mod 360` (radians for trig);
     `λ = L + 1.915·sin g + 0.020·sin 2g`; `ε = 23.439 − 4e-7·n`;
     `δ = asin(sin ε·sin λ)`; `α = atan2(cos ε·sin λ, cos λ)`;
     `GMSThours = (18.697374558 + 24.06570982441908·n) mod 24`;
     `H = (GMSThours·15 + lonDeg − α_deg)` normalised to (−180, 180];
     `alt = asin(sin φ·sin δ + cos φ·cos δ·cos H)`;
     `az = (atan2(sin H, cos H·sin φ − tan δ·cos φ)·180/π + 180) mod 360`.
  2. `export function moonPosition(date: Date, latDeg: number, lonDeg: number): { azimuthDeg: number; altitudeDeg: number; fraction: number }`
     — low-precision lunar: with the same `n`:
     `Lm = 218.316 + 13.176396·n`; `Mm = 134.963 + 13.064993·n`; `F = 93.272 + 13.229350·n`;
     `λm = Lm + 6.289·sin Mm`; `βm = 5.128·sin F`;
     equatorial via `δ = asin(sin βm·cos ε + cos βm·sin ε·sin λm)`,
     `α = atan2(sin λm·cos ε − tan βm·sin ε, cos λm)`; then alt/az as above.
     `fraction = (1 − cos(λm − λsun)) / 2` with `λsun` from the sun formulas.
  3. `export function makeSky(date: Date, origin: { lat: number; lon: number }, seed = 5): THREE.Group`
     and `export function updateSky(group: THREE.Group, date: Date, origin): void`:
     sun = `CircleGeometry(45, 24)` `MeshBasicMaterial({ color: 0xfff2b0, fog: false })`
     placed at `dir·1200` looking at the origin (`mesh.lookAt(0,0,0)`), visible
     only when `altitudeDeg > −2`; moon = `CircleGeometry(32, 24)` colour
     `0xd9dbe4`, material `opacity = 0.25 + 0.75·fraction` (transparent),
     same placement rule; stars = one `THREE.Points` of 300 mulberry32-seeded
     directions with altitude 5°–85°, radius 1300, `PointsMaterial({ size: 3, color: 0x9fb4c8, fog: false, sizeAttenuation: false })`,
     `visible` only when sun altitude < −6. `updateSky` moves/toggles the
     existing children — no allocation.
- `main.ts`: `parseUrlOptions` gains `time: Date | null` (accept ISO strings
  and `HH:MM` meaning today local; invalid → null); build the sky with
  `opts.time ?? new Date()` and `city.origin`; `setInterval` every 10 s calls
  `updateSky` with (fixed time if pinned, else `new Date()`).
- Docs: `docs/world.md` Sky section (formulas cited, accuracy note ±2°),
  `docs/integration.md` (`time` URL row, update cadence).
