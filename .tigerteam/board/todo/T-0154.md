## Goal
Our buildings are smooth extruded prisms; the reference's facades are
cluttered with ledges, AC units, balconies, pipes and rooftop tanks. Build
that detail as real geometry, generated from the OSM footprints, only near
the player, only while the cyberpunk style is active. Contract:
docs/architecture.md §4.11 "`cyberpunk` v2 (wave 20b)" → "Facade detail
geometry" and "Plumbing" (read both; every size/density is there).

## Context
- Layer contract: `src/render/punk/layer.ts` (PM-owned). The stub
  `src/render/punk/detail.ts` is already registered in `layers.ts` and wired
  by `PunkView`; replace its body, keep `export function createDetailLayer(): PunkLayer`
  with `id: 'detail'`.
- Streaming: use `CellStreamer` from `src/render/punk/cells.ts` (PM-owned)
  with buildRadius 450, disposeRadius 600, maxBuildsPerFrame 1; its
  `build(cell)` returns one Mesh per cell (or null), `dispose` frees the
  cell's geometry (share ONE material across cells; dispose it in
  `dispose()`). In `update`, call `streamer.update(ctx.sources, cam.x, cam.z, root)`;
  in `detach`, `streamer.clear(root)`. Stats: streamer stats + `triangles`
  (sum over built cells).
- Pure builder `src/render/punk/detailmesh.ts` (NO `three/webgpu` import):
  `buildDetailMesh(buildings: readonly Building[], heightAt: HeightFn): MeshData`
  using `MeshBuilder` from `src/world/mesh.ts` (PM-owned; read it — box/quad/
  triangle helpers and `toGeometry`). Seat exactly like walls:
  `normalizeRing` and `ringHeights` from `src/world/buildings.ts` (wall base =
  ringHeights.base + (minH ?? 0), roof = ringHeights.top + h); outward normal of
  CCW edge a→b = (dz, −dx)/len. Seed per building `mulberry32(id)` (copy the
  4-line PRNG from `src/world/textures.ts` into detailmesh.ts; do not edit
  textures.ts). Rooftop items must pass point-in-polygon with ≥ 2 m inset.
- Mesh material: one `MeshStandardNodeMaterial`, `vertexColors: true`,
  roughness 0.55, metalness 0.4, `normalNode = rippleNormal(u, 4.8, float(0.6))`
  with `u = { uTime, uRain }` your own uniforms (`uniform(0)`, `uniform(1)`,
  advance uTime in `update`). Convert with `toGeometry` from `world/mesh.ts`.
- Budgets are locked and unit-tested on real data
  (`public/data/london/tiles/0_0.json`, load with `fs` in the test; bucket
  with `bucketSources` from cells.ts using a one-entry sources map).
- **Never open or read any `.png`/`.jpg`.**
