## Goal
The user compared us with the reference (threejs-conference) again: our
surfaces "are still mostly smooth tiles". The reference's detail comes from
photographic PBR maps. The PM added six CC0 ambientCG sets under
`public/textures/cc0/` (see its README). Blend them into the existing
procedural cyberpunk materials so facades, roofs, roads and pavement get
real grain, cracks, joints and roughness variation — without losing the
night look. The design is LOCKED in docs/architecture.md §4.11
"PBR detail textures (wave 23, T-0167)" — read it first.

## Context
- Materials: `facade.ts` (`makeFacadeMaterials`: walls, roof, wallsOsm,
  roofOsm) and `street.ts` (`makeStreetMaterials`: road, ground, terrain,
  water). Keep both APIs and all existing tests green.
- New browser-only `pbr.ts`: `loadPbrSets(renderer)` → cached textures
  (per §4.11). The factories currently take no renderer — accept an optional
  `PbrSets` parameter (`makeFacadeMaterials(windowTex, u, pbr?)`,
  `makeStreetMaterials(u, pbr?)`); when absent (tests, fallback) the current
  procedural look is used unchanged. The PM wires `wet.ts` to pass it
  (state the exact line in your report; you may test with a local,
  uncommitted wet.ts edit, like T-0161 did).
- TSL: `texture(tex, uvNode)`, `normalMap(texture(...), vec2(s))` for walls
  (UV tangents via derivatives); for horizontal world-xz mapping build the
  normal explicitly (T = +x, B = −z, N = +y) and output a view-space normal
  (see `rippleNormal` in ripples.ts for the view-space transform). Blend
  with the existing ripple / seam normals; puddles keep ripples and stay
  mirror-smooth (the texture fades under them).
- Pure mirrors (facademath/streetmath): the distance fade, albedo clamp,
  anti-tiling rotation/offset per building seed, and the TBN mapping
  function — unit-tested.
- Performance matters (the user is on a MacBook): ≤ 3 maps per material
  path; ground anti-tiling is the only double sampling. The PM measures fps.
- **Never open or read any `.png` / `.jpg`** (including the textures —
  use them only by URL).
