## Goal
The user: "not enough neon signs — can we get a bunch of cyberpunk-style
neon signs (maybe best to start with Tokyo)". Today the rule places one
small sign on ~12 % of street-facing walls. Make Tokyo's streets DENSE with
neon — Shinjuku/Shibuya style: several signs stacked up each facade,
vertical blade signs, stacked small panels, big facade screens, two-colour
tubes, coloured glow on the walls — and double the density elsewhere. The
design is LOCKED in docs/architecture.md §4.11 "Neon v2 — dense city
profiles (wave 23b, T-0168)" — read it first, plus "Neon signs" (v1) and
the §4.2 "Tiers" paragraph (use `exteriorWalls`, as T-0165 already does).

## Context
- Current code (v1, T-0156 + T-0165): `neonplace.ts` (pure `placeSigns`,
  `WORDS`, `NEON_COLORS`), `neonatlas.ts` (64 slots), `neon.ts` (layer,
  CellStreamer, spill lights). Keep the `Sign` shape backward-compatible
  or extend it (e.g. `kind` gains `'stack' | 'screen'`, `color` →
  `text` + `border`); update all consumers in scope.
- Tokyo now has PLATEAU buildings (200 k, many with tiers) in
  `public/data/tokyo/tiles/`; the Shinjuku East-Exit cell is (−24, −4) in
  tile −6_−1 (77 buildings ≥ 8 m).
- Performance matters (the user saw stutter on a MacBook): exactly three
  merged meshes per cell; glow cards are additive, depthWrite off; no new
  point lights; the atlas must stay one 2048² texture.
- Emissive strength: keep the PM tune ×7 for tube faces (v1 value in
  neon.ts); screens use ×3.
- Word lists: no brand names. CJK in canvas text: use a generic
  font stack (`"Hiragino Kaku Gothic ProN", "Noto Sans JP", "Yu Gothic",
  sans-serif`) — the fallback must still render something.
- **Never open or read any `.png` / `.jpg`.**
